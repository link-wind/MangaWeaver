# canvas-creative-surface Specification

## Purpose
让漫画转动画画布以真实漫画、关键画面和视频为视觉主体，使用连续阅读的对话呈现创作结论，并通过可展开的角色链展示实际多 Agent 协作，使用户能清楚地定位产物、理解退回原因和提交定点修订。

## Requirements

### Requirement: 媒体优先的画布节点

系统 MUST 将媒体节点的名称与简短元信息置于画面外缘，保留原始图片比例，以轻边框表达选择。运行、失败和审查退回 MUST 可辨识，普通完成态不得在每个节点反复占用主要画面。

#### Scenario: 查看已有产物

- **WHEN** 用户打开具有漫画、关键画面和视频的项目
- **THEN** 页面展示真实产物，媒体保持原始配色与比例，详细说明和单阶段运行操作可按需找到

#### Scenario: 缩放和操作节点

- **WHEN** 用户缩小画布、右键节点或展开分组
- **THEN** 节点保持同一视觉形态，现有引用、详情、分组和删除确认能力可继续使用

#### Scenario: 分格纵向连线

- **WHEN** 漫画分格按阅读顺序纵向连接
- **THEN** 连线连接图片框上下边缘，标题文字遮住其背后的线，选中边不会覆盖节点内容

### Requirement: 连续对话与真实协作摘要

系统 MUST 在统一创作助手中提供对话和协作视图。对话以连续正文为主，关联任务以可展开的简短角色链呈现；协作视图保留实际轮次、公开说明、交接、审查和产物定位。没有证据时不得补出通过结论或虚构角色。

#### Scenario: 查看一次创作及审查退回

- **WHEN** 某轮对话关联 Creator／Reviewer 任务和审查退回
- **THEN** 对话可展开该任务的实际角色与状态，协作视图可查看完整退回原因和关联产物

#### Scenario: 流式追加与历史阅读

- **WHEN** 正在接收流式回复且用户向上阅读或展开历史过程
- **THEN** 新内容继续追加，页面不强制滚回底部，用户可通过“回到最新消息”恢复跟随

#### Scenario: 回复尚未结束

- **WHEN** 当前回复仍在输出或执行工具
- **THEN** 当前回复底部不显示复制、协作和更多操作，历史已结束回复保留操作；当前回复结束、暂停或中断后显示这些操作

### Requirement: 一体化输入和可调整工作区

系统 MUST 将节点引用、文字指令、权限和发送组织在一个输入容器中，保留自动保存、送达方式及失败信息。目录、画布和右栏 MUST 继续支持调整宽度，分隔线贴边且无阴影。

#### Scenario: 定点修改并保留草稿

- **WHEN** 用户将节点添加到对话并输入修改要求
- **THEN** 输入容器显示引用，可移除引用、选择权限并发送；保存失败有明确提示，草稿仍保留

#### Scenario: 常用和最小窗口

- **WHEN** 用户调整三栏宽度或缩小至客户端最小窗口
- **THEN** 必要的运行、停止、对话与节点操作可访问，工具不会相互遮挡，右栏正文和详情可滚动

### Requirement: 保持真实运行边界

系统 MUST 复用现有引擎、会话和产物，页面打开、缩放和视图切换不触发模型请求。停止、恢复和删除继续遵守既有功能及确认边界。

#### Scenario: 打开和预览项目

- **WHEN** 用户仅打开项目、切换协作视图或播放已有视频
- **THEN** 不提交模型任务，不把视觉稿的示例消息和计数写入真实会话

### Requirement: 独立本地创作演示

系统 MUST 在首页提供可直接发现的演示入口。演示 MUST 使用独立运行与本地预设素材，展示逐步节点、Creator／Reviewer 协作及退回反馈，不调用模型，不写入正式创作项目，不将历史媒体回放称为本次生成。

#### Scenario: 体验完整演示

- **WHEN** 用户点击「体验演示」
- **THEN** 自动进入独立画布并开始，从整页逐步展示分格、镜头编排、关键画面和已有视频，界面明确标注为本地演示

#### Scenario: 查看退回并继续

- **WHEN** 演示运行到视频审查退回
- **THEN** 暂停并保留反馈、定位和过程入口，用户点击「继续演示」后可播放已有整页预览，退回结论仍保留

#### Scenario: 停止和恢复演示

- **WHEN** 用户停止演示后再次继续
- **THEN** 从已完成步骤继续，不重新处理已完成产物，不提交远端任务
