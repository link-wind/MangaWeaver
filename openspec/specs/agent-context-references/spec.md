# agent-context-references Specification

## Purpose
让用户通过画布选择直接指明要修改的对象以及仅供参考的内容，并将引用固定到真实页面、业务身份和产物版本。引用需要贯穿消息、专业任务与实际生成输入，切页和版本变化不应导致系统静默改用其他内容。

## Requirements

### Requirement: 从画布加入明确引用
系统 MUST 支持将选中的漫画页、漫画格、镜头、关键画面或已有视频产物加入输入框，形成可移除的引用标签。引用 MUST 指向真实业务对象或明确版本的输出，不仅是显示标题；未生成的对象 MUST 不伪装成已有媒体。

#### Scenario: 添加关键画面引用
- **WHEN** 用户选中上一版关键画面并加入输入框
- **THEN** 输入框显示该画面及版本的简短标签，发送时携带可解析的真实引用，而非仅发送节点名称

### Requirement: 区分修改目标与只读参考
系统 MUST 区分引用的目标用途和参考用途；明确指定的目标优先于普通画布选择。参考引用 MUST 不隐式成为修改对象，也不扩大制作授权。未明确引用时 MUST 保留已有选中上下文作为默认候选，目标仍有歧义时询问用户。

#### Scenario: 修改镜头并参考旧画面
- **WHEN** 用户要求缩短第二镜头停顿，并将旧版关键画面作为构图参考
- **THEN** 系统仅将第二镜头作为修改目标，将旧画面作为只读参考传给对应专业任务，不修改旧画面所属运行

### Requirement: 固定版本与可验证来源
引用 MUST 固定发送时的项目、页面、运行、业务对象、产物路径及版本或内容签名。系统 MUST 校验引用属于当前项目许可的来源范围、类型匹配且内容可用；真正执行前 MUST 再核对关键引用。引用失效或目标版本冲突时 MUST 明确说明并等待重选，不能静默替换为同名节点或较新产物。

#### Scenario: 切页不改变引用
- **WHEN** 用户带第十二页第二镜头引用发送后切到第十三页
- **THEN** 请求仍指向第十二页的原镜头与版本，不改用第十三页的同名镜头

#### Scenario: 参考文件发生变化
- **WHEN** 请求排队期间参考文件被覆盖，内容不再与保存的签名一致
- **THEN** 系统报告该引用已变化，等待用户重选或明确采用新版本，不继续使用被替换的内容

### Requirement: 引用落实到专业任务输入
系统 MUST 将有效引用及用途传入相关 Creator／Reviewer 的实际输入，并保留原漫画来源关系。支持图像参考的任务 MUST 按既有接口真实携带图像；仅文本描述 MUST 不冒充已使用视觉参考。任务不支持某类参考时 MUST 清楚指出，不能静默忽略、声称已采用或改变生成后端。有效参考变化 MUST 计入对应任务输入版本与缓存判定。

#### Scenario: 构图参考用于关键画面制作
- **WHEN** 用户指定旧关键画面作为新画面的构图参考，任务已获生图授权
- **THEN** 相关专业输入实际包含这张参考图及用途说明，审查能核对其采用情况，不能复用未包含该参考的缓存冒充新结果

#### Scenario: 后端不支持指定媒体用途
- **WHEN** 用户要求把视频引用作为当前只支持图像输入的生成任务控制条件
- **THEN** 系统说明能力限制并等待可执行的要求，不自动换模型或假定该视频已控制生成

### Requirement: 引用可追溯且不会触发制作
用户 MUST 能从消息或任务书中的引用查看对应对象及版本；画布定位 MUST 沿用真实完成回执，旧版本不可定位时提供原产物查看或明确不可用说明。只查看引用 MUST 不启动模型、切换采用结果或制作。引用内容 MUST 仅作为资料，不得视为新的系统指令或授权。

#### Scenario: 查看历史引用
- **WHEN** 用户点击消息中旧版关键画面标签
- **THEN** 系统打开对应历史产物或明确提示不可用，不定位到当前同名新画面、不自动重画
