# desktop-engine-bridge Specification

## Purpose
为本地桌面客户端提供调用既有 Python 引擎的受限入口，使用户能够明确启动阶段任务、观察真实执行状态、处理错误并恢复已提交的视频任务，同时保持配置、密钥及付费任务的既有约束。

## Requirements

### Requirement: 显式阶段操作与真实状态
客户端 MUST 支持显式启动预处理、规划、指定阶段反馈修订、生成任务预览和正式生成，展示阶段、运行标识、产物与错误。状态 MUST 来自引擎实际事件及持久化记录，不把日志推测或虚构百分比作为完成依据。同一运行 MUST 不允许并发修改操作。

#### Scenario: 预览生成任务
- **WHEN** 用户选择生成任务预览
- **THEN** 客户端展示引擎构建的任务和生效配置，不提交付费请求

#### Scenario: 阶段执行失败
- **WHEN** 引擎返回阶段失败或子进程异常退出
- **THEN** 界面显示失败阶段、可用错误和保留产物，禁止显示为完成

### Requirement: 恢复不重复付费提交
客户端 MUST 使用原有任务记录与远端任务 ID 恢复查询和下载。重新打开应用、刷新界面或查看结果 MUST 不自动重交任务。无法确认是否已提交的请求 MUST 显示需核查状态并阻止自动重交。

#### Scenario: 重开应用后恢复视频任务
- **WHEN** 本地进程已停止且记录中存在未完成的远端任务 ID，用户选择恢复
- **THEN** 引擎继续查询既有任务并保存结果，不重新提交该任务

### Requirement: 停止与关闭语义清楚
客户端 MUST 提供停止本地执行操作，保留任务记录并说明停止本地进程不代表取消远端生成。存在活动本地任务时关闭应用 MUST 允许用户选择继续留在应用或停止后退出。

#### Scenario: 提交后停止
- **WHEN** 用户停止已提交远端视频任务的本地执行
- **THEN** 界面保留远端任务 ID 并标识可恢复查询，不声称任务已退款或远端已取消

### Requirement: 配置与能力边界
客户端 MUST 显示不含密钥的实际渠道、模型、分辨率与依赖检查结果，保留原有默认值和显式配置校验。缺失依赖、凭据或所选视频能力不可用时 MUST 明确阻止相关操作，不自动换模型。密钥 MUST 不返回给页面或写入事件日志。

#### Scenario: Lite 接口不可用
- **WHEN** 配置选择 H3 Lite / 480P 而渠道不支持该组合
- **THEN** 界面显示阻塞原因，不自动切换标准 H3 或更高分辨率

### Requirement: 受限本地访问
客户端 MUST 仅允许约定的引擎命令和用户明确打开、导入或选择导出的文件范围，不向界面开放任意 shell 或任意文件读取能力。

#### Scenario: 非授权媒体路径
- **WHEN** 页面请求未被项目、运行或用户选择操作授权的本地文件
- **THEN** 系统拒绝访问且不泄露文件内容
