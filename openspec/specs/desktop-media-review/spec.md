# desktop-media-review Specification

## Purpose
为漫画、关键画面和动画结果提供本地对照审查入口，使用户能结合画面、声音、字幕及模型审查判断生成质量，并区分未通过的预览与正式成片，复用既有媒体和导出产物。

## Requirements

### Requirement: 漫画与关键画面对照
客户端 MUST 支持漫画页、分格和已生成关键画面的选择、缩放及并排查看，并展示关联镜头、版本与已有审查意见。

#### Scenario: 对照人物朝向
- **WHEN** 用户选择一个镜头关键画面
- **THEN** 界面能够同时查看其来源漫画格和当前关键画面，切换已有修订版本不触发重新生图

### Requirement: 有声视频与字幕查看
客户端 MUST 支持播放、暂停、定位和音量控制，展示既有视频、对白记录及字幕产物。已有干净版与字幕版 MUST 可区分选择；对白规划文本 MUST 不冒充实际听辨字幕。

#### Scenario: 查看对白与字幕
- **WHEN** 用户打开包含原生音轨、字幕版和干净版的视频运行
- **THEN** 客户端可播放原生声音并切换已有视频版本，显示已有字幕时间和对白来源，不重复叠加已烧录字幕

### Requirement: 审查状态与导出语义
客户端 MUST 区分通过、拒绝、尚未审查及实验预览，保留模型审查和已有人工复核记录的来源差异。导出 MUST 复制用户选择的已有文件，不触发生成或修改审查结论。

#### Scenario: 导出未通过预览
- **WHEN** 用户选择导出一个未通过审查的预览视频
- **THEN** 客户端清楚标识其为未通过预览并导出选定文件，旧审查结果不变，不将它标为正式通过成片

#### Scenario: 视频文件缺失
- **WHEN** 运行记录引用的视频不在本地
- **THEN** 客户端提示缺失并允许查看其余记录，不自动提交重新生成请求
