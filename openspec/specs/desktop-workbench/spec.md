# desktop-workbench Specification

## Purpose
提供面向漫画转动画创作的本地桌面工作台，使用户能够管理漫画素材、检查分格与对白、理解镜头编排并提出反馈，在保留原作来源和既有审查机制的前提下推进生成流程。

## Requirements

### Requirement: 本地项目与历史运行
客户端 MUST 支持创建和重新打开本地项目、导入漫画页以及挂接已有运行目录，并显示素材、运行与产物的关联。打开已有结果 MUST 不触发模型调用。

#### Scenario: 打开历史结果
- **WHEN** 用户选择已有运行目录
- **THEN** 客户端展示可识别的输入和产物，缺失阶段显示未生成，无法识别的实验记录保持只读且明确标记
- **THEN** 不启动预处理、规划或视频生成

### Requirement: 素材校正保留来源
客户端 MUST 支持检查并修订矩形分格、阅读顺序、对白文本与说话人，保存为新来源版本并校验素材有效性。已有运行引用的来源 MUST 保持不变。

#### Scenario: 修正遗漏漫画格
- **WHEN** 用户在漫画页上补充分格并调整阅读顺序后保存
- **THEN** 系统生成可供预处理使用的新来源清单与裁图，显示校验结果并保留原始页面和旧来源
- **THEN** 后续使用此来源启动新运行，不覆盖旧运行的输入快照

### Requirement: 镜头与审查可追溯
客户端 MUST 展示来源脚本、静态／动作分类、来源漫画格映射、镜头时长与关键时刻、关键画面以及已有审查意见，并支持从镜头定位来源画面。尚未产生的数据 MUST 明确标识。

#### Scenario: 查看动作镜头
- **WHEN** 用户选择关联多个漫画格的动作镜头
- **THEN** 界面展示全部来源格、已规划的时间锚点和关键画面，以及对应审查问题

### Requirement: 反馈修订经过原有审查
客户端 MUST 允许用户指定现有规划阶段并提交文本反馈，由引擎完成修订和审查，区分修订前后产物。人工反馈 MUST 不直接覆盖已批准产物或将拒绝结果标为通过。

#### Scenario: 修改对话镜头节奏
- **WHEN** 用户向镜头编排阶段提交节奏调整反馈
- **THEN** 客户端调用已有阶段修订入口并展示新的规划与审查结果，旧记录仍可查看
- **THEN** 规划未通过时生成入口显示阻塞原因，不提供强制通过操作
