# book-canvas Specification

## Purpose
让用户在同一画布内浏览整本漫画，按需展开多个页面并折叠阶段内容，保持每页运行身份、素材、进度和视图可恢复；明确运行和对话的目标，沿用现有制作及审查流程。

## Requirements

### Requirement: 阶段内容分组折叠
系统 MUST 按所属页面与制作阶段分组，支持漫画分镜、镜头、关键画面及视频折叠为汇总卡，展示实际数量和状态。折叠 MUST 不改变业务产物或启动制作，拖动 MUST 不改变成员归属；展开 MUST 恢复节点身份、位置及顺序。

#### Scenario: 运行中折叠关键画面
- **WHEN** 用户收起关键画面组，运行随后保存新画面
- **THEN** 汇总卡更新数量和进度，保持收起，外部连线连接汇总卡；展开后可见真实画面

### Requirement: 书籍节点内浏览页面
系统 MUST 在书籍节点内支持缩略图浏览、文件页序跳转与页码范围选择，用户可在画布中展开页面。未展开的页面 MUST 不加载详细制作节点；浏览及选页 MUST 不调用模型。

#### Scenario: 导入整本后展开页面
- **WHEN** 用户在书籍节点选择第 2～4 页并展开
- **THEN** 画布出现三个页面分支，其他页面保持缩略图浏览，不自动执行预处理或付费制作

### Requirement: 页面与运行复用
系统 MUST 保存页面与当前运行的关联，切换或重开时复用该页已有运行；显式新运行或修订 MUST 建立新版本并保留旧产物。现有单页运行 MUST 继续可用。

#### Scenario: 来回选择已有页
- **WHEN** 用户依次选择第一页、第二页，再回到第一页
- **THEN** 第一页复用原有运行、产物和进度，不新增运行目录

### Requirement: 多页流程与整体折叠
系统 MUST 支持多页制作流程同时展示、每页整体收起及状态恢复；不同页面的同名镜头 MUST 保持独立身份，折叠连线 MUST 不悬空、不错误连接其他页面。

#### Scenario: 两页均包含 s001
- **WHEN** 两页均有编号 s001 的镜头且用户折叠其中一页
- **THEN** 另一页镜头与连线保持正常，展开恢复所属页节点，视图重开仍保留折叠状态

### Requirement: 明确制作与对话目标
系统 MUST 清楚标识当前页与运行目标；单页运行处理当前页，多页运行处理明确选择的页面并顺序执行。普通对话 MUST 沿用输入框授权，显式阶段运行 MUST 以所选阶段为边界；停止或失败 MUST 保留进度并停止后续队列，不自动提交未开始页面。节点反馈及 Agent 画布回执 MUST 绑定正确运行。

#### Scenario: 顺序运行所选页
- **WHEN** 用户选择两页并启动本地处理，在第一页处理时停止
- **THEN** 第一页保留已有产物，第二页不开始，后续查看不自动继续队列

#### Scenario: 实时刷新期间停止
- **WHEN** 制作任务执行期间画布读取产物并刷新，用户通过画布或工作台按钮停止
- **THEN** 读取进程结束不移除制作任务登记，停止实际终止本地任务，保留检查点并显示中断；后续页面和画布回执不自动继续制作

#### Scenario: Agent 定位被折叠节点
- **WHEN** Agent 请求展开当前页内一个被折叠隐藏的镜头详情
- **THEN** 系统先展开所属页面及阶段，再定位该页节点，实际完成后回传回执

### Requirement: 明确分阶段运行
系统 MUST 提供分格、脚本、编排、演出、关键画面及视频的明确运行选择，并在对应节点提供入口。显式运行 MUST 复用现有专业工具和审查，在所选阶段结束，保留产物及对话运行记录；缺少上游条件 MUST 清楚提示，不能标记成功。普通对话授权 MUST 保持独立。

#### Scenario: 分格后继续脚本
- **WHEN** 分格已完成，用户在默认对话仅本地处理时显式运行来源脚本
- **THEN** 执行脚本 Creator／Reviewer，完成后暂停；不因对话默认值只读分格，不自动生图或提交视频

### Requirement: 首批十页与即时进入画布
首页发送并选定项目后 MUST 立即进入画布。导入书籍 MUST 只转换首批 10 页，其余页面保留完整页序索引，翻页和指定页时按需加载；本地导入完成 MUST 在 Agent 回答前展示。旧全量导入书籍 MUST 继续可用。

#### Scenario: 导入二十五页漫画
- **WHEN** 用户从首页导入 25 页 CBZ 或 PDF
- **THEN** 首先呈现导入进度，索引共 25 页但仅转换前 10 页；进入下一组后转换 11～20 页；直接展开第 25 页只补载所需页面
