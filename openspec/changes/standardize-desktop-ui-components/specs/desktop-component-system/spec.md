## Purpose

使用户在首页、素材与成片库、书籍选页、画布、设置和专业编辑页面获得一致的控件、反馈与键盘操作；通过完整页面覆盖减少重复界面行为，同时保留本地数据、漫画编辑及制作操作的既有语义。

## ADDED Requirements

### Requirement: 全客户端遵循同一视觉与控件约定
客户端 MUST 对普通、紧凑和图标操作使用一致的尺寸、字体、边框、圆角与焦点表现；相同含义的成功、失败、等待及禁用状态 MUST 保持一致，白色简约视觉与紧凑导航 MUST 延续到专业页面。

#### Scenario: 跨页使用相同控件
- **WHEN** 用户从首页进入素材、设置、画布和任一专业页面
- **THEN** 同类控件遵循同一视觉与交互约定，页面不通过互相冲突的局部样式改变基本含义

#### Scenario: 字体与尺寸从单一主题继承
- **WHEN** 页面、菜单、弹窗或通知呈现正文、辅助信息和操作控件
- **THEN** 使用同一主题字体与字号层级，日志使用统一等宽字体，默认与紧凑尺寸由组件变体指定，不受旧页面的重复规则覆盖

#### Scenario: 制作工具栏随画布可用宽度调整
- **WHEN** 用户调整目录或对话宽度使中央画布变窄
- **THEN** 制作范围、终点选择和操作按钮保持同一垂直中心，左右浮条有一致留白且可整体换行，不相互覆盖或裁切

#### Scenario: 最小窗口切换专业页面
- **WHEN** 用户在支持的最小窗口从已滚动的规划页切到视频结果
- **THEN** 新页面从顶部显示，镜头内容与审查按正确顺序排布，视频填满预览容器且不改变画面比例

### Requirement: 输入与选择不丢失编辑语义
输入、数值、对白、反馈、下拉和页面选择框 MUST 支持原有合法值、禁用与校验行为；中文输入法、草稿保存和页面选择 MUST 不因控件迁移误触发提交或画布拖动。

#### Scenario: 修改对白后查看设置
- **WHEN** 用户编辑对白并打开、关闭设置
- **THEN** 按既有保存边界保留编辑内容，返回原页面且不提交制作

#### Scenario: 节点内选择页面
- **WHEN** 用户勾选页节点用于制作
- **THEN** 仅更新页面选择，不拖动节点或误运行阶段

### Requirement: 内容页签与模式切换行为一致
内容页签 MUST 提供明确的选中状态、方向键焦点导航和可关联的内容区域；模式切换 MUST 保留合法模式值。切换返回后 MUST 保留仍有效的草稿与选择。

#### Scenario: 键盘切换创作与详情
- **WHEN** 用户用键盘切换右侧页签并返回创作
- **THEN** 可以访问当前可用面板，创作草稿保留，不可用详情不被误选

### Requirement: 弹窗和确认保持安全的操作边界
设置、选材、引用预览与确认弹窗 MUST 支持焦点约束、合理关闭和入口回焦；取消 MUST 不执行操作。删除确认 MUST 展示实际清理范围，说明生成结果及下游产物永久清除、原始漫画保留，并优先聚焦取消。

#### Scenario: 取消删除后续节点
- **WHEN** 用户打开清理范围并取消
- **THEN** 生成文件、画布节点、运行记录和原始漫画均不因取消发生删除

#### Scenario: 取消重新读取
- **WHEN** 用户在放弃未保存修改的确认中取消
- **THEN** 保留当前编辑内容并返回原入口

### Requirement: 进度和反馈准确可见
客户端 MUST 对未知耗时显示不确定进度，只显示真实百分比；普通完成反馈可自动消失，错误、待确认及恢复操作 MUST 保持可发现且可操作。

#### Scenario: 等待远端任务
- **WHEN** 模型任务尚无真实进度数值
- **THEN** 显示执行中而不编造百分比或提前完成

#### Scenario: 普通完成与失败反馈
- **WHEN** 文件保存成功或任务失败
- **THEN** 前者显示轻通知，后者保留错误摘要、必要操作与原始详情入口

### Requirement: 会话浮层和业务折叠可访问
会话浮层 MUST 支持分支选择、上下文查看、关闭与回焦；核心协作、候选和业务详情 MUST 使用一致的展开状态与键盘行为，技术原始报告可继续默认收起。

#### Scenario: 展开协作记录后关闭会话浮层
- **WHEN** 用户在阅读协作记录时查看会话分支并关闭浮层
- **THEN** 返回合理入口，已有展开状态与阅读内容不被重置

### Requirement: 画布上下文菜单保持节点范围
节点菜单 MUST 支持右键和 Shift+F10，提供与原节点权限一致的引用、详情、折叠及删除操作；关闭 MUST 回到对应节点或操作规定的目标。

#### Scenario: 键盘打开节点菜单
- **WHEN** 用户在节点上按 Shift+F10 后按 Escape
- **THEN** 菜单关闭并回焦原节点，不触发引用或删除

### Requirement: 节点搜索支持一致的列表操作
节点搜索 MUST 支持输入、方向键、确认、空结果和关闭；检索范围 MUST 明确为已加载节点，确认结果 MUST 沿用真实页面加载和画布定位回执。

#### Scenario: 搜索尚未加载页面的节点
- **WHEN** 输入没有对应已加载结果的查询
- **THEN** 显示空结果与范围说明，不伪造定位成功或自动调用模型

### Requirement: 分栏在空项目与小窗口保持可用
左栏、画布和右工作区 MUST 保留宽度约束、折叠、保存／恢复、键盘调整与双击复位；未打开项目时 MUST 仍可调整。分隔线 MUST 贴合区域边缘且无阴影，调整 MUST 不改变节点数据或丢失草稿。

#### Scenario: 拖动过程中保存宽度
- **WHEN** 用户持续拖动任一分隔线，面板回调更新已保存宽度
- **THEN** 底层 Panel 的挂载初始尺寸保持稳定，手势不因父组件重新渲染被取消；关闭再打开对话栏时采用最新保存宽度

#### Scenario: 旧布局重开与小窗口调整
- **WHEN** 有已有保存宽度的用户重开客户端并调整到支持的最小窗口
- **THEN** 恢复有效宽度，三栏必要操作可访问，画布响应实际尺寸且不因调整覆盖节点位置

### Requirement: 左侧导航和整本选页保持轻量
导航 MUST 保留首页、成片、素材、项目及设置入口和当前项；整本漫画 MUST 保留紧凑目录、按需选页、页码范围及分页，不把大量书页重新常驻左栏。

#### Scenario: 通过页码范围选择漫画
- **WHEN** 用户输入合法页面范围并打开选中页面
- **THEN** 仍按原加载边界打开真实页面并显示选择反馈，不一次展开全书

#### Scenario: 收起目录与查看已成片的运行
- **WHEN** 用户收起侧栏或查看已有成片的运行
- **THEN** 收起时仅显示带可访问名称的全局图标入口，不残留换行的目录标题；同一已成片运行不同时出现在独立运行和项目成果中

### Requirement: 全页面迁移保留业务产物语义
迁移 MUST 覆盖全部可用页面及主要分支，包括成片库、选材、来源查看、候选与日志；漫画坐标、阅读排序、候选采用、结果导出、媒体释放与音轨 MUST 保持原语义。

#### Scenario: 从候选到结果导出
- **WHEN** 用户切换候选、采用合法结果并导出选中视频
- **THEN** 操作对应同一真实运行与版本，导出选中素材并保留已有音轨，不因组件替换重复提交生成
