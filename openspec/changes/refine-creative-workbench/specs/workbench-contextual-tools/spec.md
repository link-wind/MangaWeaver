## Purpose

围绕漫画素材、当前节点和既有候选提供就近且明确的操作，使选材、编辑、预览与采用具有不同含义，并保持漫画来源、审查状态和用户原有创作上下文一致。

## ADDED Requirements

### Requirement: 共享浮层遵循键盘与焦点约定
选材弹层和引用菜单 MUST 使用共享基础组件处理键盘、焦点和边界定位，沿用现有白色视觉。关闭选材 MUST 保留输入草稿并返回入口焦点；关闭引用菜单 MUST 返回创作输入，不触发生成。

#### Scenario: 取消选材
- **WHEN** 用户输入中文要求后打开选材并按 Escape
- **THEN** 弹层关闭、提示词保持，焦点回到选材入口且没有模型调用

### Requirement: 选材返回保留创作上下文
工作台 MUST 同时支持素材库管理与输入区选材模式，使用相同的显式导入记录。关闭或取消选材 MUST 返回原输入并保留提示词和引用；选材成功 MUST 显示漫画身份，整本漫画继续进入选页流程，不自动提交生成。

#### Scenario: 输入一半后选择漫画
- **WHEN** 用户从已有提示词的输入区打开选材并确认一本漫画
- **THEN** 返回原输入，漫画被加入且提示词和引用仍存在，没有付费调用

### Requirement: 节点编辑明确保存与执行
未选中节点 MUST 优先展示产物与短状态；选中后 MUST 提供针对该对象的编辑、审查和已有阶段操作。保存草稿与启动制作 MUST 清楚区分，长文本 MUST 可在不依赖画布缩放的详情区阅读与编辑。

#### Scenario: 修改镜头要求但未运行
- **WHEN** 用户选中动作镜头、修改要求并保存
- **THEN** 草稿关联该镜头，既有产物保持真实状态，不因保存而触发模型或宣称新审查通过

### Requirement: 候选预览不改变正式采用
工作台 MUST 区分当前采用产物与候选预览，展示已有审查和来源版本。正式采用 MUST 经过原有来源一致性及审查检查；被拒绝或不匹配候选不能通过预览界面直接替换正式产物。

#### Scenario: 查看被拒绝候选
- **WHEN** 用户打开一个被 Reviewer 拒绝的历史关键画面
- **THEN** 可以预览并查看原因，当前采用产物不变，界面不提供绕过审查的采用操作

### Requirement: 可搜索节点且设置不破坏画布
工作台 MUST 能按已加载节点的页码、名称或阶段搜索并定位，目标被折叠时显式展开必要分组。已有本机环境与版本信息 MUST 在明确的设置分类内呈现，关闭设置后保留视口和输入；不存在的功能不得显示为可操作设置。

#### Scenario: 搜索折叠镜头
- **WHEN** 用户搜索已加载的某页镜头并点击结果
- **THEN** 系统展开必要分组并定位该镜头，不扫描或生成未加载页面，不改变其他任务归属
