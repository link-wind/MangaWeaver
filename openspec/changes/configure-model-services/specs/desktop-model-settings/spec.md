## Purpose

让本地漫画创作用户在统一设置弹窗中管理模型厂商连接、独立凭据、制作任务模型和生成偏好，明确配置与验证的区别，并将显式选择可靠传递给现有制作引擎。

## ADDED Requirements

### Requirement: 分类设置与配置编辑
客户端 MUST 提供模型服务、任务模型、生成偏好、本机环境、关于五类设置，保留当前工作区与未保存内容的关闭确认。

#### Scenario: 编辑后关闭
- **WHEN** 用户修改连接或任务配置后关闭设置
- **THEN** 提醒保存或放弃，取消关闭继续保留草稿；保存成功才表示配置已落盘。

### Requirement: 现有厂商与任务能力
系统 MUST 允许添加和编辑已有适配器的命名连接、接口、模型条目和按能力分开的凭据，并在四类任务配置时执行引擎已有组合限制。

#### Scenario: 配置任务模型
- **WHEN** 用户选择创作、生图、视频审查与视频生成服务
- **THEN** 选择来自配置目录；审查沿用创作服务，不支持的厂商组合或视频输出参数明确阻止保存，不自动更换模型。

### Requirement: 本地凭据与可靠保存
系统 MUST 读取现有环境配置，保留未编辑凭据及无关字段，以本地原子写入保存更改；读取响应不得包含原始密钥，旧版本不得覆盖并发编辑。

#### Scenario: 保留凭据与版本冲突
- **WHEN** 用户未输入新的Key就保存，或配置文件已被其他入口修改
- **THEN** 既有Key保留；版本冲突时拒绝覆盖并保留界面草稿，密钥不出现在结果和日志中。

### Requirement: 检查与执行边界
本地检查 MUST 只做配置校验，不能发起模型调用；真实接口测试 MUST 由用户单独手动触发。保存与本机环境修改 MUST 在活动制作结束或停止后执行，保存后的选择用于后续任务。

#### Scenario: 检查或活动任务期间保存
- **WHEN** 用户检查配置或尝试在制作中保存
- **THEN** 检查无网络调用；活动制作期间阻止写入并清楚说明，不改变运行任务的模型与凭据。

### Requirement: 模型接口的真实远端测试
模型服务页 MUST 允许用户逐个手动测试模型，并使用当前草稿中的接口地址、Key 和模型。测试 MUST 不保存草稿、不自动重试、不自动切换模型；文本发送最小文本请求，图像和视频发送真实请求。图像和视频测试前 MUST 提示可能产生费用，视频只验证任务受理，不等待或下载成片。

#### Scenario: 验证未保存的连接
- **WHEN** 用户修改接口地址或输入新Key后点击某个模型的“测试”按钮
- **THEN** 使用当前未保存值发起一次对应请求，页面显示测试中、成功或失败；设置文件保持不变，测试结果不得包含原始Key。

#### Scenario: 修改已测试配置
- **WHEN** 用户切换连接、接口类型或模型，或修改接口地址、Key、模型目录
- **THEN** 旧测试结果立即失效并从当前状态中移除；即使之后改回相同值，也不把旧结果当作当前验证。
