## Why

现有设置仅能修改本机路径，模型供应商、独立凭据和任务模型仍需编辑环境文件。用户已确认模型服务与任务模型视觉稿，需要将现有引擎配置接入统一设置弹窗。

## What Changes

- 按视觉稿提供模型服务、任务模型、生成偏好、本机环境、关于五个分类。
- 管理已有厂商适配器的命名连接、地址、独立凭据和模型列表，支持添加与编辑。
- 显式配置四类制作任务与已有输出参数，校验真实厂商组合限制。
- 复用本地 `.env` 原子保存，保留其他配置，原密钥不回传；检查配置只做本地校验。
- 保留画布上下文、未保存提醒和运行保护，完成客户端验收并重新打包。

## Capabilities

### New Capabilities

- `desktop-model-settings`: 模型服务、任务分配、生成参数的读取、校验、保存和设置弹窗交互。

### Modified Capabilities

无。

## Impact

修改现有 React 设置组件、Electron 命令白名单与 Python 配置入口；新增一个本地设置读写模块与少量关键验证。不新增供应商框架、网络服务或依赖，不调用付费模型。
