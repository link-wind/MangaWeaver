## Context

依据已确认的 `docs/SETTINGS_MODEL_SERVICES_DESIGN_2026-11-06.md` 与两张视觉稿。沿用 Toonflow 本机快照设置分类与主从表单方式、Manga2Animate 固定提交 `29543daacbf58c609c360bad840649b0de6b4866` 的环境配置与明确模型选择；桌面读写为本项目增量。现有 Config、各厂商客户端与 JSONL/IPC 保持直接调用。

## Goals / Non-Goals

Goals：把现有配置接入视觉稿，少量直接模块完成读取、校验、用户手动接口测试与保存，已有环境可无损继续使用。

Non-Goals：任意供应商插件、自动换模型、自动触发远端验证、每个Agent单独模型、重写客户端。MiniMax继续按已支持模型与分辨率明确选择，不以设置页存在代替接口验证。

## Decisions

- 在一个 Python `desktop_settings.py` 中管理配置读写；白名单命令通过现有引擎调用，不建设HTTP服务。
- `.env` 中一个带版本的JSON字段保存非秘密连接目录与任务选择，连接独立凭据使用专用环境字段。保存时将显式任务选择投影到现有标准环境字段，现有CLI与客户端直接生效；不新增运行时供应商注册层。
- 环境文件读取只返回凭据是否存在，空的新Key表示保留。新Key经stdin传入、原子写入本机权限受限文件，不返回或写日志。保留其他字段，使用原文件签名防止旧页面覆盖外部编辑。
- 支持多命名连接，但现有共享地址／共享Key限制须同步校验：幻灵、词元文本与图像共用各自base；Kie共享Key与地址。UI根据创作服务筛选生图选项，后端作同样校验。
- 没有目录时从现有Config与凭据导入。外部直接修改规范字段时显示提醒，保存仍以当前显式表单为准，不静默切换。
- 全局保存与本地检查统一位于底栏。设置组件持有草稿；变更未保存时关闭确认。运行期间允许查看与编辑，禁止写入；本机路径更改沿用即时保存。
- 控件复用现有shadcn/Radix。按职责拆分模型服务和任务／偏好内容，不添加新依赖。
- “测试接口”由用户在每个模型上显式点击，直接使用当前表单草稿，不要求先保存；调用一次、不自动重试、不回写`.env`。文本测试发送最小生成请求，图像测试要求返回图像，视频测试提交一个四秒首帧任务并只确认`task_id`，不等待成片。结果按当前服务、接口类型、地址、Key、模型目录和模型绑定；任一配置变化都会清除旧结果。
- 本地“检查格式”和远端“测试接口”保持两个明确动作。图像、视频按钮旁提示真实请求与可能费用；错误响应中的当前Key必须脱敏。

## Risks / Trade-offs

- [表单选择超出现有客户端组合] → 前后端校验并明确解释约束，不能仅靠模型名宣称支持。
- [环境文件有人工修改] → 保留原始未知内容并校验签名；冲突后由用户重新载入。
- [设置仍只代表配置正确] → 状态使用“已配置 · 未验证”，本地检查不显示远端验证成功。
- [长模型名与最小窗口] → 内容滚动、字段可换行，主从列按可用宽度收缩；实机检查常用和最小尺寸。
