## Why

目前首页 prompt 只作为创作要求传给规划阶段，阶段调用依赖按钮，用户无法通过一个对话入口完成整本漫画导入、选页、画布操作和中途修改。增加统一创作 Agent，让用户表达目标，系统通过明确工具调用现有专业流程，并在信息不足时询问和等待。

## What Changes

- 首页与画布对话使用同一个创作 Agent，支持结构化工具调用、结果反馈、提问、跨轮恢复和停止。
- 支持整本 MOBI、PDF、CBZ 漫画及单页图片导入，建立页面索引与缩略图；整本未指定页码时询问用户，单页直接选择。
- 将现有脚本、镜头编排、演出、分镜 Creator／Reviewer 封装为可委派的专业任务，复用现有流水线、反馈修订、阶段暂停和产物，不另建专业推理实现。
- 总 Agent 可以选中、聚焦、布局节点、打开详情；内容修改通过业务工具更新真实产物，刷新画布。
- 项目级会话先于运行存在，保存对话、选页问题和任务结果；选页后绑定对应运行。
- 延续显式模型配置、有限重试、单运行互斥和远端任务恢复；刷新不调用模型，已授权的付费动作不反复询问。

## Capabilities

### New Capabilities

- `creative-agent`: 统一对话、上下文、工具循环、专业任务委派、授权与恢复。
- `manga-book-import`: 整本漫画拆页、索引、缩略图、页码选择及单页快捷路径。
- `agent-canvas-control`: Agent 画布视图操作、执行结果反馈和业务内容同步。

### Modified Capabilities

无。当前 `openspec/specs/` 尚无主规格，既有工作台和制作行为在其他变更下定义；本变更新增入口，保留其审查、版本、任务提交与凭据边界。

## Impact

- Python：新增 `agent/loop.py`、`agent/tools.py`、按需新增会话和动作协议；新增漫画文件导入；对现有规划流水线增加最小任务入口。
- 提示词：新增 `prompts/agent/`；专业提示词继续复用。
- 桌面：扩展受限 IPC／JSONL、统一对话、页面选择、React Flow 命令执行与上下文回传。
- 文件：新增项目级 `session.json` 和书籍页面索引，运行目录和原有产物格式尽量保持。
- 依赖：MOBI 使用 mobi／KindleUnpack 独立 CLI；PDF 使用 pypdfium2，CBZ 使用本地 ZIP 解析，缺失能力清楚报错，不自动安装或换解析后端。
- 不新增 Web 服务、数据库、多 Agent 通信框架、通用插件系统或自动模型降级。
