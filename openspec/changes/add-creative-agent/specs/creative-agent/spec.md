## Purpose

提供统一的漫画转动画创作对话入口，让用户通过自然语言委派专业制作任务，系统结合当前素材和画布上下文执行、询问并恢复，同时保持真实审查结论与既有产物版本的一致性。

## ADDED Requirements

### Requirement: 统一多轮创作对话
系统 MUST 在首页与画布使用连续的项目级会话，支持在尚未选择页面或建立运行前接收要求与附件。系统 MUST 保存必要上下文、用户消息、助手回复、工具结果引用和等待中的问题。查看或重新打开会话 MUST 不自动调用模型或执行制作任务。

#### Scenario: 重开后继续选页
- **WHEN** Agent 正在等待用户选择漫画页面，用户关闭并重新打开项目
- **THEN** 系统展示原问题和素材，用户回答后可继续同一会话，不重新拆页或自动生成

### Requirement: 模型驱动的工具循环
系统 MUST 结合用户要求、当前项目状态和已选节点决定回答、提问或调用受限工具，并将工具实际结果反馈给 Agent 决定下一步。系统 MUST 支持同一用户请求中先读取状态再执行任务，且在等待用户回复时暂停执行。循环达到有限步数上限时 MUST 保留进度并清楚结束，不无限重试。

#### Scenario: 多步请求
- **WHEN** 用户指定书籍第 94 页并要求自动分格
- **THEN** Agent 先完成有效选页，再执行预处理，收到真实结果后告知完成情况

#### Scenario: 缺少目标
- **WHEN** 存在多个可能的镜头目标且用户未选中节点，只说“这里慢一点”
- **THEN** Agent 请求确定目标，不擅自选择或修改镜头

### Requirement: 委派专业任务与保留审查
总 Agent MUST 能委派来源脚本、镜头编排、镜头演出和分镜任务。各专业任务 MUST 复用现有 Creator／Reviewer 反馈循环、候选选择与检查点，返回完成、需用户决策、阻塞或失败以及产物引用。必要审查未通过 MUST 不返回正式通过或进入依赖该结果的生成。执行层 MUST 校验前置产物、目标和版本。

#### Scenario: 编排审查失败
- **WHEN** 编排任务在有限迭代后仍未通过审查
- **THEN** 总 Agent 获取草案与问题并向用户说明，不将其作为正式计划提交生成

#### Scenario: 缺少前置来源脚本
- **WHEN** Agent 尝试直接编排，但当前没有有效来源脚本
- **THEN** 工具返回缺少前置结果，由 Agent 在授权范围内补齐或询问用户，不伪造输入

### Requirement: 授权与单次执行
系统 MUST 根据用户明确请求和已记录授权执行付费任务，允许用户一次授权清楚的制作范围，并在范围内继续而不逐次确认。只要求导入、选页、分格或查看时 MUST 不隐式调用付费制作。Agent 模型调用的付费性质 MUST 在发送入口明确。系统 MUST 保持同一项目会话及同一运行的修改互斥，保留请求与任务结果用于恢复；恢复和重开 MUST 不自动重复付费提交。

#### Scenario: 只导入漫画
- **WHEN** 用户要求打开一本漫画并选页
- **THEN** 系统可执行对话模型调用和本地素材处理，但不会自动启动规划、生图或视频生成

#### Scenario: 已明确授权范围
- **WHEN** 用户明确要求将已选页面规划并生成动画，且配置支持请求
- **THEN** 系统在该范围内继续调用任务；发生新费用范围或模型配置变更时再请求决定

### Requirement: 停止与错误可恢复
系统 MUST 展示真实的工具和阶段进度，支持停止本地执行并保留检查点。存在远端任务时 MUST 保留其标识，说明本地停止不等于远端取消。工具失败 MUST 返回可用错误与保留产物，不伪造成功、不自动换供应商或模型。

#### Scenario: 停止视频制作
- **WHEN** 已提交远端视频后用户停止本地执行
- **THEN** 会话保留任务状态和标识，后续明确恢复查询时使用原任务，不重新提交
