## Purpose

相邻镜头的关键画面生成共享衔接参考：后一镜头能看到前一镜头的结束画面，使色调、光照与角色状态在镜头切换处延续，并由分镜审查检查衔接质量。

## ADDED Requirements

### Requirement: 跨镜头衔接参考传递

生成某镜头第一张关键画面时，系统 MUST 将前一镜头已选关键帧中时间最大的画面作为衔接参考传入生成输入；镜头第二张及以后、首个镜头、前一镜头无已选关键帧时不传入。

#### Scenario: 传给首张锚点

- **WHEN** 生成镜头 B 的第一张关键画面且镜头 A（前一镜头）已有已选关键帧
- **THEN** 生成输入的媒体与载荷包含镜头 A 时间最大的关键帧，载荷字段为 previous_shot_final_image。

#### Scenario: 不传给后续锚点

- **WHEN** 生成镜头 B 的第二张关键画面
- **THEN** 生成输入不包含跨镜头参考字段，衔接由本镜头已选锚点承接。

#### Scenario: 首镜头无参考

- **WHEN** 生成镜头清单的第一个镜头
- **THEN** 载荷中 previous_shot_final_image 为空，生成行为与既有流程一致。

### Requirement: 衔接参考参与输入签名

衔接参考 MUST 进入分镜生成与审查的输入签名；设计身份（plan_signature）MUST 不因衔接参考变化。

#### Scenario: 换参考后旧缓存

- **WHEN** 同一设计的候选元数据存在但衔接参考发生变化
- **THEN** 报告输入不一致并要求显式重跑分镜，不静默复用旧图。

### Requirement: 审查覆盖镜头间衔接

分镜审查 MUST 在提供衔接参考时检查候选与前一镜头结束画面的场景、光照与角色状态延续；姿态 MUST 按当前锚点判断，不因不复刻前一画面判错。

#### Scenario: 衔接断裂

- **WHEN** 候选的场景色调或角色状态与前镜头结束画面明显断裂
- **THEN** 审查可以以衔接问题拒绝该候选并给出具体建议。
