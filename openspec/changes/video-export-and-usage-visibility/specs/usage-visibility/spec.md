## Purpose

运行用量可只读汇总：模型调用与词元、视频段提交次数（含重提归档）与请求时长，不调用模型、不推断金额。

## ADDED Requirements

### Requirement: 只读用量汇总

系统 MUST 提供只读的用量汇总：聚合运行目录内各 `*_usage.json` 的成功调用数与词元数；扫描视频任务状态统计每段提交次数、归档重提次数与请求时长，写入 usage_summary.json；汇总 MUST 不加运行锁、不调用任何模型。

#### Scenario: 含重提的段

- **WHEN** 某段经历一次作废重提后重新提交
- **THEN** 该段提交次数为活动候选与归档条目之和，归档任务 ID 不丢失。

#### Scenario: 与生成并发

- **WHEN** 汇总在生成进行中执行
- **THEN** 不因运行锁被拒绝，读到的是各文件的完整快照。
