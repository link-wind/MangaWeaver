## Purpose

将选定镜头清单和视觉条件转换成 MiniMax H3 的实际生成任务，分别执行静态首帧与动作首尾帧路线，审查候选及接缝并组织成片，同时明确模型入口能力与计划意图之间的边界。

## ADDED Requirements

### Requirement: MiniMax H3 能力匹配

系统 MUST 使用选定的 MiniMax H3 后端，并在提交任务前确认实际入口支持请求模式、素材与时长。MUST NOT 将普通参考图当作首尾帧控制或自动换用其他视频模型。

#### Scenario: 入口不支持首尾帧控制
- **WHEN** 动作任务需要首尾帧，而选定 MiniMax H3 入口没有对应能力
- **THEN** 系统在付费提交前指出能力缺口并停止该路线，保留规划产物，不把动作任务伪装成已支持的参考模式

### Requirement: 按镜头类型构建生成任务

系统 MUST 为静态镜头构建单首帧任务；为动作镜头按关键帧顺序构建相邻首尾帧任务，保留镜头、源格、关键帧及生成段的对应关系。不同机位或场景之间的切镜 MUST NOT 自动变成首尾帧连续过渡。

#### Scenario: 关键瞬间位于中段
- **WHEN** 动作镜头包含 K0、K1、K2 三张依次排列的关键帧
- **THEN** 输出 K0→K1 和 K1→K2 两个任务，并记录目标与请求时长；K1 是两段的共享条件，而不是整个镜头的默认首帧

### Requirement: 时长限制显式处理

系统 MUST 区分设计时长、模型请求时长与成片实际时长；接口无法满足计划时 MUST 明确报出，不能静默拉长动作、自动加速或以插帧假装精确执行原计划。

#### Scenario: 片段短于模型最小时长
- **WHEN** 计划的相邻关键帧间隔不在接口支持范围内
- **THEN** 提交前指出对应生成段和限制，使用户可修改计划，不发送未经记录的替代时长

### Requirement: 候选审查与镜头连接

系统 MUST 对视频候选检查提示与视觉条件符合度、关键端点、意外切镜及可见缺陷；对动作镜头的组合结果检查接缝和节奏，对镜头间结果检查叙事与视觉衔接。MUST NOT 将共享输入关键帧视为运动连续性的保证。

#### Scenario: 接缝出现不合理停顿
- **WHEN** 两段视频在共享关键帧附近出现明显减速后重新启动
- **THEN** 评审记录镜头与接缝问题，结果不能仅因首尾画面接近就被标为无问题

### Requirement: 完整剪辑与可追溯导出

系统 MUST 按选定镜头顺序连接生成段并剪辑成片，保留原始候选、任务记录与评审结果；导出成功 MUST 以必要镜头完整及最终视频可读取为依据。首版提供统一规格的有声版，保留并连接模型原生音轨；生成提示要求同步环境声、动作音效及本段适用的原作对白，不逐段生成背景音乐。音频 MUST 按视频边界同步裁剪，缺少音轨 MUST 明确报错，不静默导出无声版。

#### Scenario: 镜头缺失或拼接失败
- **WHEN** 必要镜头没有可用结果，或最终拼接失败
- **THEN** 系统保留已有素材并报告失败，不跳过镜头后宣称完整成片，也不把不存在的输出路径报告为成功

### Requirement: 彩色动画持续一致

视频请求 MUST 明确彩色二维动画目标并沿用关键帧和角色配色；Reviewer MUST 检查无依据的变色、黑白和彩色闪变及局部褪色，发现阻断问题时记录实际视频时间范围并拒绝通过。合理明暗和本身白色或灰色物体 MUST NOT 被当作缺色。

#### Scenario: 视频中途从彩色变为黑白
- **WHEN** 候选在无设计依据时出现整体褪色或黑白和彩色切换
- **THEN** 评审指出候选和可见时间范围，accepted=false，不因端点正确而接受全段

#### Scenario: 原始片段包含原生声音
- **WHEN** 已选片段包含音轨并进行连接或共享边界去重
- **THEN** 输出保留音轨并按视频裁剪同步处理音频，视频审查检查可听的声音同步及接缝问题

### Requirement: 日语对白准备与准确引用

系统 MUST 在视频提交前用 Creator／Reviewer 将已审查中文对白翻译成日语，为每句保留来源格、对白索引和说话人，并分配到一个生成段的有效时间窗口。系统 MUST 区分开口对白、内心独白与明确唱词（singing），唱词使用已审查日语并允许无伴奏旋律，使用稳定说话人和明确日语标签，不让 H3 自行翻译或自由补词。未知说话人、遗漏、重复或时间越界 MUST 明确阻止提交。

#### Scenario: 静态漫画格含一句中文对白
- **WHEN** 生成约十秒的静态对话镜头
- **THEN** 来源中文保留为字幕文本，审查后的日语台词通过 H3 对白标记传入，人物仅在指定发声时段演绎对应内容

### Requirement: 实际声音对齐中文字幕

系统 MUST 根据实际视频听辨记录而非仅凭计划时间导出中文字幕，保留来源中文与实际日语记录；字幕 MUST 随音视频边界同步裁剪。系统 MUST 保留无字幕有声文件及 SRT，再输出带中文字幕的视频；未通过声音评审不得冒充正式成片。字幕字体 MUST 在视频付费提交前检查可读。

#### Scenario: 实际台词比计划稍早开始
- **WHEN** 视频 Reviewer 确认日语台词正确但实际发声时间与计划不同
- **THEN** 字幕使用实际听辨时间，同步显示对应中文原文，不以计划窗口直接覆盖

### Requirement: 显式关键帧临时托管

幻灵入口 MUST 按配置选择 Kie 或 Uguu 上传关键帧，不自动更换服务或视频模型。Uguu MUST 不接收模型密钥，并在匿名下载核对图片哈希后使用公开链接；缓存 MUST 记录内容签名及过期时间。已有视频任务 ID MUST 保留，上传失败不作为重复视频提交的依据。

#### Scenario: 已提交部分视频后上传配额耗尽
- **WHEN** 用户显式改变关键帧上传服务并恢复运行
- **THEN** 继续查询已有视频任务，只为确认尚未提交的片段执行新提交，不因托管服务变化重建成功任务
