## Purpose

把漫画中的离散关键瞬间转成有来源依据的动画镜头序列，通过静态与动作分类、镜头编排、演出时间安排和视觉参考审查，避免将所有漫画格都机械地作为独立视频首帧。

## ADDED Requirements

### Requirement: 原作脚本与改编选择区分

系统 MUST 对漫画人物、事件、对白和空间信息形成来源脚本，保留原漫画依据，并区分可见事实、推断与改编选择。评审 MUST 能对照原漫画，不只比较生成文本。

#### Scenario: 原作仅展示动作高潮
- **WHEN** 漫画显示击中瞬间而未画出动作起始
- **THEN** 来源脚本记录已见的击中事实，并将补充的入点或过渡标为改编选择

### Requirement: 跨格镜头编排与分类

系统 MUST 结合上下文识别事件并输出有序镜头清单，为每个输出镜头指定 `static` 或 `action`、来源格、表达目的、时长及编排理由。系统 MUST 支持多格合为一个镜头及一格支持多个镜头，保留原作事件因果顺序和关键内容覆盖。

#### Scenario: 连续动作后接反应
- **WHEN** 多个漫画格描述一次连续攻击，随后一格是适合停留的旁观者反应
- **THEN** 编排可输出引用多个源格的动作镜头和独立静态反应镜头，不强制一格一镜头

### Requirement: 依照呈现需求分类

系统 MUST 依据是否需要展开主要状态变化及控制关键瞬间来分类，而非以所有可见运动作为动作标准；静态镜头允许局部运动和轻微运镜。

#### Scenario: 无主要状态变化的对话镜头
- **WHEN** 一个构图即可表达对话内容，只有口型或眨眼等局部运动
- **THEN** 系统可将该镜头分类为静态，并说明分类依据

### Requirement: 动作镜头的时间位置与演出

系统 MUST 为动作镜头明确入点、原漫画关键瞬间的位置、强调或停顿、出点及有序关键帧目标时间；MUST NOT 默认将原漫画姿态置于首帧。静态镜头 MUST 能直接进入单张分镜制作，不强制展开动作设计。

#### Scenario: 原漫画位于镜头中段
- **WHEN** 演出将原漫画姿态确定为镜头高潮
- **THEN** 计划区分入点画面、高潮画面及所需出点，保存目标时间与各画面的原作关联

### Requirement: 与路线一致的视觉产物

系统 MUST 为静态镜头输出单张选定分镜，为动作镜头输出选定演出要求的关键画面序列；视觉评审 MUST 同时检查原作约束与授权的演出变化，不因起始姿态不同于原漫画高潮就直接判错。

#### Scenario: 动作入点画面审查
- **WHEN** 新分镜表现选定方案中的动作开始，原漫画表现同一动作的高潮
- **THEN** 审查以起始阶段要求和原作身份、场景约束判断画面，不要求起始图复刻高潮姿态

### Requirement: 有限轮次定向反馈

系统 MUST 在配置轮次内将理解问题反馈给脚本、分类和整体镜头关系问题反馈给编排、动作镜头节奏问题反馈给演出、视觉实现问题反馈给分镜制作；MUST 区分较优候选与可采用结果，保留正确内容及成套版本。

#### Scenario: 分镜暴露演出问题
- **WHEN** 视觉评审发现关键画面实际需要换机位，不能在同一连续镜头内表达
- **THEN** 反馈明确指出相关镜头与证据，下一轮回到编排或演出修订，而不是只反复重画；达到轮次上限仍有阻断问题时保留结果并报出未解决项

### Requirement: 彩色动画关键画面

系统 MUST 生成完整配色的二维动画关键画面，不因来源漫画或前序参考为黑白就要求黑白输出。系统 MUST 沿用已确认角色配色；未知配色 MUST 明确标为改编选择，不冒充原作事实。单帧与序列 Reviewer MUST 接收已审查的角色描述，检查配色和一致性，整体黑白或明显局部上色不能作为彩色产物通过。

#### Scenario: 输入为黑白漫画
- **WHEN** 来源漫画为黑白，但角色资料已有发色和服装配色
- **THEN** 关键帧按角色资料生成完整彩色人物及场景，审查不因有颜色而判定背离漫画画风

#### Scenario: 持续滑行的跟拍首尾主体近似
- **WHEN** 两张图保持角色及空间一致，演出为持续滑行或周期奔跑，但主体姿态近似
- **THEN** 序列审查不能仅凭相似就断言视频必然静止；可记录执行风险并交实际视频核验，明确的状态或空间矛盾仍应阻断

#### Scenario: 对话气泡跨漫画格边框
- **WHEN** 来源提供整页参考及转录，某句气泡横跨当前格和相邻的无台词反应格
- **THEN** 逐格审查结合整页核对说话人和单次归属，不因裁图不完整要求删除原文或将同一句重复分配给相邻格
