## Purpose

将用户选定的一段漫画整理成按阅读顺序排列的可引用素材，提供对白和角色参考信息，并允许复用人工准备或检查后的结果，为后续跨格镜头编排提供可靠来源。

## ADDED Requirements

### Requirement: 有序漫画来源

系统 MUST 为漫画素材提供稳定的来源格标识与阅读顺序，并保存原图关联和分格图片；跨页输入 MUST 保留用户指定的页面顺序。

#### Scenario: 处理多页连续素材
- **WHEN** 用户按顺序提交多页漫画
- **THEN** 输出各格的唯一标识、页面来源和阅读顺序，后续镜头可准确引用

### Requirement: 来源文字与角色参考

系统 MUST 生成或接收 OCR 文本和角色描述，保留角色参考图关联；无法识别的信息 MUST 标记为不确定，不作为已确认原作事实。

#### Scenario: 漫画文字无法可靠识别
- **WHEN** 某格对白识别不完整
- **THEN** 输出保留识别结果及疑问，使用户能够修正，而不补写新的原作对白

### Requirement: 已有预处理结果复用

系统 MUST 允许输入已整理的有序漫画格、文本与角色参考，完成必要格式检查后进入规划，无需重复运行检测与 OCR。

#### Scenario: 使用人工准备的案例
- **WHEN** 用户提供有效来源清单及已有文本和角色参考
- **THEN** 规划能够读取这些产物，不强制再次调用漫画预处理模型
