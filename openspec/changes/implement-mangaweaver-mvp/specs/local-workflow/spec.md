## Purpose

提供可独立运行三个阶段的本地工作方式，使用户能够准备漫画素材、检查生成计划、继续指定运行并追溯本地结果，无需部署服务或数据库即可进行小规模漫画转动画实验。

## ADDED Requirements

### Requirement: 显式测试规格与有限请求重试

系统 MUST 对 Gemini 明确的 429、500、502、503、504 使用有限重试，幻灵最多 5 次并记录尝试状态；图片与视频创建结果不明时 MUST NOT 自动重复提交。用户明确允许本次标准 H3 时，系统 MUST 将 MiniMax-H3 和 768P 记入独立测试配置，不改变 Lite 480P 默认值。

#### Scenario: Gemini 连续服务端失败
- **WHEN** 相同模型的 5 次请求仍为服务端错误
- **THEN** 系统保存失败尝试记录，停止依赖该规划的生产流程，不以独立视频样例冒充完整验收

### Requirement: 幻灵多模态独立凭据

系统 MUST 支持用户显式选择幻灵域名，分别使用独立密钥调用 Gemini 规划／评审、GPT Image 参考图生图和经核实的视频接口。GPT Image MUST 保留漫画参考及前序关键帧输入、原有视觉提示词和收费状态记录。系统 MUST NOT 将模型列表中的标准 H3 视作 H3 Lite 480P 的支持证据，也不得自动换模型或渠道。

#### Scenario: 幻灵未核实 Lite 能力
- **WHEN** 用户指定幻灵且仅能获取标准 H3 模型标识，缺少 Lite 480P 首尾帧合同
- **THEN** 系统保存配置，停止视频创建和查询，保留可独立运行的规划与生图并说明能力缺口

### Requirement: 词元规划与生图独立密钥

系统 MUST 支持用户显式配置词元 Gemini 进行规划与评审，文本／多模态请求读取 CIYUAN_API_KEY，生图读取 CIYUAN_IMAGE_API_KEY。既有 Creator／Reviewer 和 JSON 结构校验 MUST 保持；失败不得以人工脚本冒充模型结果或自动退回其他供应商。

#### Scenario: 用户切换规划渠道
- **WHEN** 用户指定 MODEL_PROVIDER=ciyuan 并继续真实漫画页规划
- **THEN** 系统使用指定文本密钥及词元原生多模态 JSON 请求，按独立配置保存新运行，未打通接口时保留失败证据并不发布通过计划

### Requirement: 独立指定词元生图与成片目标

系统 MUST 允许显式配置词元 Nano Banana 生图，并保留 Kie 规划／评审与 H3 Lite 480P 视频路线。词元 MUST 使用实测可用的 Gemini 原生接口发送参考图，收费请求结果不明时 MUST NOT 自动重复提交。指定 TARGET_DURATION 时，编排镜头时长总和 MUST 与之相符。

#### Scenario: 真实漫画单页制作十二秒短片
- **WHEN** 用户提供已分格漫画页并指定词元生图和 TARGET_DURATION=12
- **THEN** 系统制作总设计时长十二秒的镜头计划，以漫画格及前序关键画面为参考生成所需锚点，保留提交状态和实际消耗证据

### Requirement: 分阶段本地执行

系统 MUST 提供预处理、规划、生成的独立命令入口，允许用户指定输入素材、运行目录与模型配置；帮助信息 MUST 说明各阶段所需输入。

#### Scenario: 只运行规划阶段
- **WHEN** 用户提供有效的预处理结果并执行规划命令
- **THEN** 系统输出来源脚本与选定镜头计划，不隐式提交视频生成任务

### Requirement: 运行结果可检查与继续

系统 MUST 将一次运行的有效配置、阶段结果、评审反馈和生成任务记录写入可明确识别的本地目录，允许用户显式选择继续运行或重跑阶段。密钥 MUST NOT 写入运行记录。

#### Scenario: 继续已提交的视频任务
- **WHEN** 指定运行已保存视频任务 ID，但尚未下载完成结果
- **THEN** 系统查询该任务并记录结果，不因重新启动命令就重复提交同一生成请求

### Requirement: 错误显式暴露

系统 MUST 在必要输入缺失、结构不合法或外部调用失败且必要重试耗尽时清晰报错，保留已有产物；MUST NOT 静默替换模型、默认把未评审候选标记为通过或跳过必要镜头后宣称完整成功。

#### Scenario: 关键素材缺失
- **WHEN** 选定镜头计划引用不存在的关键画面
- **THEN** 生成命令指出对应镜头与缺失素材并停止，已有结果保留

### Requirement: 显式 Kie.ai 模型接入

系统 MUST 允许显式选择 Kie.ai 作为规划、参考图生图和视频评审的调用渠道，保留已有业务数据结构、有限反馈循环和 MiniMax H3 Lite 480P 视频生成选择。MUST 校验返回 JSON，不将提示词约束宣称为供应商原生 Schema 强制能力；异步生图 MUST 保存任务 ID，恢复时不得自动重复提交。

#### Scenario: 使用 Kie.ai 进行多模态评审
- **WHEN** 用户配置 Kie.ai 并提交本地图片或视频进行评审
- **THEN** 系统通过已核实的上传和媒体输入接口发送完整素材，返回结果经结构校验后保存，记录模型与消耗但不保存密钥
