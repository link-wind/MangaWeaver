## Purpose

为 MangaWeaver 提供显式调用的 MangaShelf 平台接入能力，将指定章节版本的漫画页下载到本地，并把用户选定的成片和可选字幕回传平台。保留原作来源、内容摘要和发布回执，以便在独立阅读平台与本地创作工具之间追溯素材和动画版本。

## ADDED Requirements

### Requirement: 显式平台调用与凭据隔离

系统 MUST 通过独立 CLI 命令接收平台地址和平台接入 Token；平台操作 SHALL 不要求生成运行目录或持有生成运行锁，不向平台传递模型 API Key，不在导入清单或发布回执中保存平台 Token。

#### Scenario: 主动导出不启动生成

- **WHEN** 用户使用平台地址、接入 Token、章节版本 ID 和输出目录执行 `shelf-export`
- **THEN** 系统仅执行素材导出，不启动预处理、Agent 或模型生成任务

### Requirement: 页面下载与来源清单

系统 MUST 下载平台导出的页面并逐页核验 SHA-256；全部下载完成后 SHALL 保存协议版本、平台、作品、章节、章节版本、阅读方向及逐页来源 ID、摘要和本地相对路径。

#### Scenario: 下载成功

- **WHEN** 导出页面均成功下载且摘要与平台声明一致
- **THEN** 系统保存页面文件和 `mangashelf_manifest.json`，报告已导入页数

#### Scenario: 摘要不匹配

- **WHEN** 某页实际摘要与平台声明不同
- **THEN** 系统明确报告该页摘要不一致，保留已下载文件，不把本次导出报告为成功

### Requirement: 成片发布与回执

系统 MUST 在用户显式执行 `shelf-publish` 后，携带来源页范围和发布请求键创建平台发布草稿，通过预签名地址上传视频及可选字幕，等待平台验证为 READY 后请求发布，再查询并保存发布回执。发布请求键 SHALL 用于平台幂等处理；回执 MUST 包含协议版本、请求键、动画 ID、版本 ID、版本状态及平台返回的观看地址。

#### Scenario: 成片通过验证并发布

- **WHEN** 用户指定成片、来源范围和发布请求键，平台上传及版本验证成功
- **THEN** 系统请求发布并将查询到的状态保存为 `mangashelf_receipt_<请求键>.json`

#### Scenario: 平台验证失败或超时

- **WHEN** 平台版本返回 FAILED，或验证未在有限等待时间内完成
- **THEN** 系统明确报错，不继续请求发布，不将该次结果显示为已发布
