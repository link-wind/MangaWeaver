## Purpose

使全客户端的对话、弹层、菜单、状态、环境配置和专业页面遵循同一套轻量交互与视觉约定，减少技术信息噪音，并保留真实错误、待处理问题和用户已有的本地配置与制作行为。

## ADDED Requirements

### Requirement: 对话和任务信息分层
对话 MUST 保留公开流式正文、专业协作、待送达要求和必要错误；会话设置和原始数据默认收起，历史阅读不被新增文字强制打断。组件替换 MUST 不创建第二套任务或消息执行机制。

#### Scenario: 阅读旧协作记录
- **WHEN** 用户展开历史审查而当前任务继续追加文字
- **THEN** 继续保留用户阅读位置，并提供返回最新消息入口

### Requirement: 页面共享简约交互基准
各页面 MUST 使用一致的菜单键盘行为、短状态和紧凑标题，专业页面不得依靠额外宣传性标题组织任务；小窗口的必要操作 MUST 可达，分栏保持细线无阴影。

#### Scenario: 键盘使用项目菜单
- **WHEN** 用户打开项目或画布菜单并使用方向键和 Escape
- **THEN** 可以选择或关闭菜单，焦点返回合理入口且不误执行制作

### Requirement: 本地环境支持单项修改
设置 MUST 支持仅更改一个已知路径字段，取消不修改其他字段，运行中禁止更改；检测与日志 MUST 显示可理解摘要并保留原始详情。

#### Scenario: 只更改 FFmpeg 路径
- **WHEN** 用户在设置中仅选择 FFmpeg 目录
- **THEN** 其他已配置路径保持，检测展示实际结果且不调用付费模型

### Requirement: 设置使用共用弹窗组件
设置 MUST 通过全局左栏打开已有 Dialog 组件，打开前 MUST 沿用保存边界，原页面保持挂载。设置 MUST 支持焦点约束、Escape、关闭按钮和点击遮罩关闭，关闭后焦点返回入口。设置 MUST 使用紧凑分类，标题与分类固定，内容内部滚动；路径标签、值和更改按钮逐行对齐，长路径与最小窗口不得导致水平溢出。

#### Scenario: 从规划进入设置后返回
- **WHEN** 用户从规划视图进入设置并返回
- **THEN** 设置通过共用弹窗显示，关闭后回到相同规划及已保存草稿，查看不提交生成

#### Scenario: 小窗口查看长路径
- **WHEN** 用户在最小窗口查看包含较长路径的设置页
- **THEN** 路径可折行，行操作仍对齐可用，环境检查可通过页面内滚动访问
