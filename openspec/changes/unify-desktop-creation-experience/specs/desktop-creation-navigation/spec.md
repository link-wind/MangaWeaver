## Purpose

让用户在首页、素材、整本选页、画布与专业视图之间始终理解当前创作对象、页码和运行范围，明确查看、编辑、保存和执行的不同作用，减少重复入口而不破坏既有项目恢复与来源追踪。

## ADDED Requirements

### Requirement: 专业视图属于同一项目工作区
专业视图 MUST 显示当前运行或页身份，提供返回画布入口，保留原视口和草稿保存边界。首页项目入口 MUST 用真实动作名称，播放与打开项目 MUST 可区分。

#### Scenario: 从规划返回画布
- **WHEN** 用户从某页打开完整规划后返回
- **THEN** 返回同一工作对象的画布，保留原位置及已保存要求

### Requirement: 制作范围与操作明确
工作台 MUST 区分运行至某阶段、仅执行当前阶段和恢复远端查询；节点和全局操作 MUST 保留原范围约束，任务页不得重复展示完整上游制作流程。

#### Scenario: 查看视频任务
- **WHEN** 用户进入任务视图
- **THEN** 可以检查视频提交和查询状态，上游来源与规划通过导航查看，查看不会触发模型

### Requirement: 素材与选页语义一致
素材管理 MUST 支持先预览再用于创作；选材模式 MUST 保留已有提示词。整本页选择 MUST 显示选择范围并由明确操作展开，继续每次按需加载页面。

#### Scenario: 浏览整本漫画
- **WHEN** 用户单击某页缩略图
- **THEN** 只更新选择，未点击展开前不切换工作运行或提交制作

### Requirement: 节点菜单显式指向操作对象
画布 MUST 支持节点右键和 Shift+F10 菜单，添加到对话或用作参考 MUST 使用右键对象的固定引用，不自动发送消息。删除节点与删除后续节点 MUST 弹窗确认并显示影响范围，取消不得修改视图；运行期间 MUST 禁止删除。

#### Scenario: 另一个节点已被选中
- **WHEN** 用户选中 A 后右键 B 并添加到对话
- **THEN** 草稿新增 B 的目标引用，打开创作对话且保留已有文字，不引用 A 或发送消息

#### Scenario: 删除折叠列的后续节点
- **WHEN** 用户右键折叠列并确认删除后续节点
- **THEN** 根据展开后的连线移除已有下游节点，保留当前列及列内内容，其他独立页面不变

### Requirement: 节点删除永久清理生成结果并保护来源
客户端 MUST 在确认后实际清理所选节点及依赖它的下游生成文件，并同步更新关联规划。原始漫画页、整本漫画和素材库 MUST 保留。删除后续 MUST 保留当前层及其上游，不得波及无关页面和平行镜头。部分规划删除 MUST 撤销完整计划并保留待审草案，旧检查点不得恢复已删结果。旧隐藏状态 MUST 不再应用，也不得自动转为物理删除。

#### Scenario: 删除关键画面
- **WHEN** 用户确认删除一张关键画面
- **THEN** 该画面全部候选、相关审查、对应镜头视频及成片实际清除，其他镜头关键画面和原始漫画保留

#### Scenario: 删除镜头后续
- **WHEN** 用户确认删除镜头的后续结果
- **THEN** 保留镜头编排及演出，清除其关键画面、视频及共享成片，其他镜头文件保留

### Requirement: 永久删除需要具体确认与受限执行
确认弹窗 MUST 展示待清理文件与记录的实际范围，明确生成结果不可恢复及原始素材保留。含远端任务时 MUST 说明本地删除不取消平台任务且失去本地查询记录。取消 MUST 零写入。执行 MUST 校验项目归属、文件未变化、运行内路径和运行锁；失败 MUST 清楚报错并刷新，不得伪报成功。

#### Scenario: 取消或确认期间产物变化
- **WHEN** 用户取消，或产物签名已变化
- **THEN** 不删除任何产物，签名变化时要求重新确认清理范围
