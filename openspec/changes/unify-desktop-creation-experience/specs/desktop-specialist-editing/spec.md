## Purpose

为漫画分格、对白校正、镜头规划、关键画面比较和视频结果提供一致且以当前对象为中心的编辑查看体验，保证用户无需理解底层文件名也能找到产物，同时继续遵守原来源和审查约束。

## ADDED Requirements

### Requirement: 分格编辑有明确模式和保存反馈
分格页面 MUST 区分浏览选择与绘制新框，突出当前格的对白编辑，坐标作为辅助详情；保存 MUST 呈现实际成功或错误，不覆盖新编辑。

#### Scenario: 浏览漫画分格
- **WHEN** 用户处于浏览模式并点击图面已有框
- **THEN** 选中对应格而不创建新框，可修改该格文字并保存新版本

### Requirement: 规划与候选以视觉对照为主
规划 MUST 显示当前镜头来源、时长、关键瞬间与审查；候选 MUST 提供图片切换，明确预览与当前采用，保留不可采用原因及原校验。

#### Scenario: 预览另一候选
- **WHEN** 用户点击一个未采用候选缩略图
- **THEN** 只更新预览，当前正式产物不变，未通过检查的候选仍不能采用

### Requirement: 视频任务与结果分层
视频任务 MUST 首先展示镜头和可理解状态，原始 ID 与请求细节按需查看；结果 MUST 区分成片与片段，优先显示已有成片，导出跟随所选文件。

#### Scenario: 打开混有候选的视频运行
- **WHEN** 运行同时存在成片与多个片段
- **THEN** 默认选择已有成片，片段独立分组，字幕和审查仍可查看
