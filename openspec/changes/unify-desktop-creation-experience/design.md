## Context

问题见 proposal.md。现有 Electron／React 19／Vite 使用 React Flow 12，专业页面与画布共用运行产物，但视觉与操作有分叉。上一变更的保存队列、来源版本、媒体租约及回执继续生效。保留工作区未提交改动，不迁移或清理用户产物。

参考 docs/TOONFLOW_INSPIRED_DESIGN.md 与 docs/TOONFLOW_ENGINEERING_REFERENCE.md 中记录的本地 Toonflow 快照；制作引擎继续沿用 Manga2Animate 29543daacbf58c609c360bad840649b0de6b4866。本轮不改变模型请求，因此不新增 H3 能力核验或付费任务。

## Goals / Non-Goals

目标是让当前对象、操作范围、阶段状态和返回路径清楚可见，并统一真实页面的视觉。非目标包括重写 Agent／引擎、加入时间线剪辑器、云账户、通用素材管理、无限撤销、自动重试和全新状态框架。

## Decisions

### 页面与交互矩阵

| 区域 | 实施内容 | 保留机制 |
| --- | --- | --- |
| 导航外壳 | 专业视图紧凑标题、返回画布、清晰页／运行身份，隐藏重复装饰标题 | 现有 view/tab、切换前 flush、画布视口 |
| 首页 | 紧凑统一的附件菜单；当前项目提供明确继续入口，不用保存位置文案冒充导航 | 输入草稿、主动导入、即时进入画布 |
| 成片库 | 明确打开项目／播放两种操作，保留有成片过滤 | 原所属项目定位与本地扫描 |
| 素材库 | 管理模式先预览再用于创作；选材模式直接选择 | 同一素材数据、导入去重 |
| 整本选页 | 单击仅选中，明确当前选择数与展开；范围与跳转关系清晰，取消双击触发制作类导航 | 每组 10 页、懒加载、来源映射 |
| 画布 | 细化节点类型详情，聚拢对象操作，保留折叠与按页工作范围 | React Flow、回执、单阶段运行 |
| 对话 | 回复、专业协作、队列、错误分别呈现；高级会话和技术详情收起 | 原轮次、真实任务、停止、分支、公开文字 |
| 分格与对白 | 浏览／画框模式，当前格编辑为主，坐标收起，明确保存反馈 | 像素坐标、顺序、OCR、版本保存 |
| 完整规划 | 紧凑标题、镜头列表与对照；来源／节奏／审查清楚，版本名称可读 | 同一 ProductionPlan 与反馈入口 |
| 候选 | 缩略图切换、当前采用和不可采用原因 | 原受限采用检查 |
| 生成任务 | 从 App 拆为直接组件；以镜头和状态为主，远端 ID 与 JSON 折叠，不重复完整上游操作 | 原 generate/resume 与阻止原因 |
| 结果 | 成片／片段分组，优先成片，字幕和审查按需展开 | 媒体授权、原音轨、导出 |
| 设置 | 共用 Dialog 弹窗，紧凑横向分类；路径与更改按钮逐行对齐，检测状态清楚，关于保留 | 同一 settings.json、原生文件选择 |
| 公共状态与日志 | 统一短状态、空态、字段与菜单；日志摘要和原始记录分层 | 原错误、事件、明确手动执行 |

### 组件取舍

继续 React Flow。菜单和弹层采用已有本地 Radix 组合，逐个替换首页／项目／画布入口；不复制整套 UI 模板。assistant-ui 试用仅替代阅读视口，却带来额外消息投影和完整运行时，移除这一局部接入，恢复原有跟随阅读逻辑并保留本地样例。暂不加入 react-resizable-panels，保持已有宽度与无阴影分隔线。

### 状态与运行所有权

画布右上运行至阶段，节点仅运行对应阶段；任务页只做视频提交、查询和产物检查，不重复来源及规划按钮。统一 scope 文案但不新增业务调度。查看、选择、打开、保存和生成具有不同按钮名称；隐藏高级细节不能隐藏错误、待回答问题或恢复入口。全局 banner 仅保留现有非任务错误，任务错误继续留在所属卡片。

### 样式与布局

沿用系统字体、白底、轻字重、黑色主按钮与少量紫色；专业页删除装饰英文眉题与宣传性标题。只清理受本轮影响的样式规则，不大规模重写所有旧 CSS。列表与详情内部滚动，窄窗口允许专业页单列；分隔线贴边无阴影。

### 节点右键与删除

复用现有 Radix 菜单，通过 React Flow 的节点右键事件在指针处打开，支持 Shift+F10。添加到对话和用作参考显式捕获右键节点的固定引用，不依赖另一个已选中节点；复用现有草稿保存，打开对话但不自动发送消息。

删除是永久清理本地生成结果，不再保存 hidden_nodes，也不提供恢复入口。预览命令解析当前产物，返回待删除文件和待更新记录；确认时校验内容签名、项目归属并取得运行锁。删除路径限制在对应运行内，input/、原始整页和参考素材保留，运行外素材与素材库从不清理。旧隐藏状态不再应用，也不自动转为物理删除。

删除节点包含依赖它的派生产物：分格清除对应裁图及全部规划下游；规划清除脚本和后续；镜头清除对应编排条目、演出、关键画面和视频；关键画面清除全部候选及对应镜头视频；视频清除所选候选与共享采用记录；成片清除导出、字幕及最终审查。删除后续保留当前层：漫画列保留分格，规划保留脚本，镜头列保留镜头和演出，关键画面列保留画面，视频保留片段。原漫画、书/页容器作为保留的来源入口，删除只清理其派生结果。

删除部分镜头或画面后，保留其他镜头产物，清理旧完整检查点并写入待审草案；需显式重跑及审查，不直接作为完整计划生成。整段对白、合并任务表及成片为共享结果，相关片段删除时同步清理。折叠列按业务身份定位，不依赖坐标，不波及其他页。实验与模拟运行明确拒绝删除。

两项删除使用已有 Dialog 二次确认，列出实际文件数、关联记录和可展开清单，写明原始素材保留、生成结果不可恢复。含远端任务时说明仅删除本地记录、不取消平台任务且不能再从本地恢复查询。取消零写入；运行中禁止删除。先保存草稿，完成或失败后刷新真实磁盘产物，错误明确呈现，不报告虚假成功。

### 设置修改

复用已有 configure 文件对话框，增加可选且受限的设置字段参数，旧无参数路径仍可用于首次配置；取消不保存，运行中禁止修改。根目录更改仍使用现有发现与验证逻辑，不开放任意 IPC 写文件。

用户最新明确要求设置使用已有的弹出窗口组件，采用与选材一致的本地 Radix Dialog。打开前沿用保存边界，原页面保持挂载，关闭回到原工作对象，焦点返回入口。分类与标题固定，内容区内部滚动；两个分类采用紧凑横向导航，不再占用第二条宽侧栏。路径行按标签、路径、操作三列对齐，长路径折行，小窗口可访问全部设置。支持关闭按钮、Escape 和点击遮罩，不另外建设弹窗或路由系统。

## Risks / Trade-offs

- [导航精简隐藏熟悉入口] → 保留四个专业视图，明确命名与返回画布。
- [组件替换丢焦点或草稿] → 沿用 flush、原 ID、现有 draft refs，独立项目验证。
- [短状态掩盖实际失败] → 失败详情和操作可展开，未知状态保留原值。
- [样式覆盖互相影响] → 专业页共享根类约束作用域，主画布不做视觉替换。
- [验收依赖本机界面工具] → 如受锁屏等限制，记录具体未完成项，不以构建通过代替实机结果。

## Migration Plan

先完成方案与入口基线，再按导航／对话、专业页面、素材／设置、样式顺序实施。运行现有桌面回归、构建与 strict 校验；用无密钥离线样例从客户端查看各入口。旧 OpenSpec 验收不自动完成，不删除已保存运行。无需数据迁移；回退仅撤销本轮组件修改，不回写旧磁盘产物。
