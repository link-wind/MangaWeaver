## Purpose

让用户在对话中检查工具何时被请求、实际输入是什么、执行到了哪里以及得到什么结果。工具展示需要与真实执行和产物绑定，同时保留现有授权、输入校验、画布回执与远端任务恢复规则。

## ADDED Requirements

### Requirement: 工具过程实时关联
工具调用 MUST 具有稳定身份、所属轮次／子会话、目标与输入版本，展示准备、运行、已有增量进展和真实终态。参数和详情 MUST 默认折叠；没有增量能力的工具 MUST 如实显示等待，不编造百分比、日志或预计完成时间。

#### Scenario: 等待远端视频
- **WHEN** 已提交视频任务正在查询
- **THEN** 对应工具块显示原任务的真实查询状态和已有片段，与最初提交关联，不额外创建重复调用卡

### Requirement: 完整校验后才能执行
部分工具名或参数 MUST 仅作未提交展示，只有完整动作通过结构校验、目标／版本核验和授权检查后才可执行。无效、截断或已停止的响应 MUST 不产生内容修改、画布命令或付费提交。

#### Scenario: 参数在流中被截断
- **WHEN** 模型已输出部分制作参数后连接中断
- **THEN** 工具块标为未执行或中断，系统保留诊断但不猜测补全参数执行

### Requirement: 结果与副作用可追溯
工具终态 MUST 来自真实回执或产物；命令已提交、文件已保存、内容审查通过 MUST 分别表达。画布控制 MUST 继续等待完成回执；远端任务提交不明时 MUST 核查原标识，不能因对话重答、断流或分支操作重复提交。

#### Scenario: 画布尚未完成定位
- **WHEN** Agent 已发出定位命令但尚未收到客户端完成回执
- **THEN** 工具仍显示等待，Agent 不声称定位成功
