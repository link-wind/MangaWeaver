## Context

用户已确认 `docs/prototypes/toonflow-canvas-v1/index.html` 及两张完整截图。当前前端是 Electron／React／React Flow，已实现分组折叠、三栏伸缩、节点菜单、引用和对话／协作 trace。现有工作区含此前未提交修改，本轮只增量修改目标界面。

参考本地 Toonflow 的 `messageList.vue`、`messageInput.vue`、`canvasControls.vue`：连续消息、按需操作和统一输入容器。保留 Manga2Animate 对应的原三阶段及 Creator／Reviewer 数据与调用；参考项目没有对应桌面画布，因而此处只调整现有桌面呈现，不改引擎实现、提示词、MiniMax 模型或能力核实边界。

## Goals / Non-Goals

**Goals:**

- 将用户确认的层级、密度、配色和媒体表达落到真实 React 组件。
- 复用现有 task／activity／handoff／report 映射，提供简短、可展开的真实协作摘要。
- 清理目标区域重复样式，让一处规则负责一类控件，保留共享开源交互组件。

**Non-Goals:**

- 不复制 HTML 原型的硬编码对话、图片路径、假按钮或固定节点坐标。
- 不重建多 Agent 框架，不改变已保存的画布位置和模型生成行为，不为视觉工作提交付费请求。
- 不重写首页、素材库和全部专业页面。

## Decisions

1. **视觉稿作为视觉依据，真实节点作为布局依据。** 媒体采用外置轻标题、白色薄边框、原始比例和低饱和选中线；分组沿用现有展开与合并，不强行把完整业务图塞进原型的固定三列。保留用户位置和 React Flow 的平移／缩放。
2. **统一右栏头部，保留详情。** “创作助手”作为稳定标题，详情入口放在头部操作中，进入详情后可返回对话。正文只展示结论、流式公开文字、用户问题与必要错误；有任务时以折叠摘要补充角色链，完整记录在协作中。
3. **角色摘要从已有映射派生。** 使用 `turnParts` 和 `roleChain` 关联任务及活动；历史独立任务也可在对话中找到摘要。运行状态遵守已有 busy／interrupted 映射，失败不得因简化而隐藏。不新增后端字段。
4. **输入容器减层。** 目标作为紧凑上下文，权限与送达方式收进底部工具；自动保存继续执行，正常保存状态通过轻量提示表达，失败提示及手动重试可见。保留已有快捷键和中文输入法判断。
5. **复用组件，收敛 CSS。** 使用现有 shadcn/Radix、Tabs、Popover、InputGroup、Trace 与 Resizable；直接修改目标规则，删除重复的节点、对话和输入样式，不引入另一个 UI 栈。
6. **两档窗口及离线流程验收。** 使用真实漫画运行的独立副本检查媒体和右栏；通过已有本地模拟任务检查逐步节点、停止恢复和协作。截图必须来自正式 React 页面，不能以原型代替实施结果。

## Risks / Trade-offs

- [真实图比原型节点多] → 不硬编码缩放、折叠状态与固定位置；保留全览、查找和已有位置，重点核验媒体及右栏层级。
- [简化输入误移除权限或草稿状态] → 保留真实权限选择、送达选择、错误与手动保存操作，核对原有发送路径。
- [合并摘要误报审查成功] → 仅使用真实活动的 accepted 和任务状态，未知时只显示阶段或任务状态。
- [旧 CSS 多处覆盖] → 修改及删除相关规则，再核查实际计算样式和最小窗口；不影响非目标专业页面。

## Migration Plan

只修改桌面呈现，不迁移项目数据。运行现有测试、构建和 OpenSpec 严格校验后，实际客户端验收并打包 `.app`；记录截图、完成范围和未覆盖边界。用户没有要求 Git 提交、推送或归档，本轮不执行这些操作。

## 安装版对照修正（2026-11-05）

实机显示默认全流程缩放仅 24%，这不能作为正常工作的初始视图。初始取景改为同一镜头的演出、关键画面和视频：优先选中对象，其次已退回的视频，否则第一个有画面的镜头。完整节点和保存坐标保留，全览按钮仍查看全流程；不通过篡改项目坐标实现视觉匹配。历史项目没有协作会话时明确提示缺少会话，不补造 Agent 消息。视频退回状态读取已有导出审查记录，不能将“已下载”等同于审查通过。

## 独立创作演示入口

用户追加要求体验完整流程。首页提示词容器下方常驻「体验演示」，复用已有模拟任务和 JSONL／任务账本／画布消息刷新，在独立 `results/simulations/` 运行中回放第94页本地素材。素材固定在 `examples/creative-demo/`，不依赖用户历史运行目录。创建后自动开始，支持停止续跑，在视频审查退回时暂停；再次继续仅展示已有的整页有声预览，保留未通过结论，不伪造重生成或修订通过。演示回复按本地步骤逐段追加，不称为模型 SSE 输出。

该补充仅修改本地演示脚本及前端入口，不引入模型客户端、远端任务或新框架。演示输入只读，不能发送创作或历史重答；正式项目的数据和制作流程不受影响。界面和消息明确标注本地预设与不调用模型。

## 用户追加的阅读字号调整

对话栏字号在视觉稿基础上小幅提高一档：正文及反馈13px、标题14px、阶段角色11px、阶段状态10px、输入14px。只调整创作栏内的文字层级，不放大画布、三栏尺寸或控件高度；此追加决定优先于此前视觉稿的字号值。

## 连线与回复收尾修正

分格读序的上下 Handle 放到媒体容器边缘，避免连线停在外置标题上方。媒体仍使用原有薄边框，标题与说明仅在文字所在区域使用画布底色遮住底层线，不把节点改回整张白卡。选中边不提升到节点前景，避免穿过媒体和文字。

对话按合并后的回复保留运行状态。当前回复执行期间不渲染底部复制、协作和更多操作；包括文字已结束但工具尚在执行、以及首段文字先于任务记录到达的情况。历史已结束回复保留操作；结束、暂停或中断后当前回复显示操作。反馈正文中的定位和查看过程入口保持可用。
