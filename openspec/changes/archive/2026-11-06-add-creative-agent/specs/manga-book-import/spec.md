## Purpose

让用户从整本漫画或单页图片开始创作，通过本地页面提取、明确的页面索引和缩略图完成素材选择，避免手工解包漫画，并将选定页面可靠地交给既有预处理和动画制作流程。

## ADDED Requirements

### Requirement: 本地整本与单页导入
系统 MUST 支持 MOBI、PDF、CBZ 整本漫画与 PNG、JPEG、WebP 单页图片。系统 MUST 保留原文件，按来源顺序建立稳定页面索引、页面图像与缩略图。导入整本 MUST 不上传整本文件给模型；后续按需读取用户指定页面。缺失解析依赖、不支持的文件或加密内容 MUST 清楚报错，不自动安装、绕过保护或替换输入。

#### Scenario: 导入已有 MOBI
- **WHEN** 用户选择项目素材中的有效 MOBI，且解析依赖就绪
- **THEN** 系统在本地提取按来源顺序排列的页面，展示真实页数和缩略图，原文件不变

#### Scenario: 依赖缺失
- **WHEN** 用户导入 MOBI 但解析工具未安装
- **THEN** 系统指出缺失工具并保留原素材，不显示导入成功或自动切换其他解析方式

### Requirement: 明确页码并询问选择
系统 MUST 以从 1 开始的文件页序作为默认页码，展示缩略图辅助确认，不混淆印刷页码。整本未指定页面时 MUST 询问用户并等待，支持自然语言回答和点击选择；已明确有效页面时 MUST 直接使用，越界时 MUST 提示有效范围。单页输入 MUST 直接进入该页流程而不询问第几页。

#### Scenario: 整本未指定页码
- **WHEN** 导入一本漫画且用户未指定页面
- **THEN** 系统展示书籍和页面选择入口，询问改编哪页，回答前不执行该页预处理或制作

#### Scenario: 指定有效页码
- **WHEN** 用户说“用文件中的第 94 页”且该页存在
- **THEN** 系统选中对应整页并显示预览，不再次询问页码

#### Scenario: 输入单页
- **WHEN** 用户添加单张漫画页并要求分格
- **THEN** 系统直接选定这页并执行分格，不经过整本选页问题

### Requirement: 页面与运行可追溯
系统 MUST 将选定书籍、文件页序、整页来源与运行关联，并保留初始创作要求。切换页面或修改已有制作内容 MUST 遵循现有新运行或修订版本机制，不覆盖旧页成片及其任务。

#### Scenario: 从第 94 页切换第 95 页
- **WHEN** 第 94 页已有制作产物，用户要求改编第 95 页
- **THEN** 系统为第 95 页创建对应运行并切换画布，保留第 94 页的结果和来源关系
