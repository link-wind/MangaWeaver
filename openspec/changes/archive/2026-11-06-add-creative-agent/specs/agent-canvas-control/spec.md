## Purpose

让创作 Agent 能根据自然语言与当前选择操作画布，并将制作结果准确呈现为可追溯的节点。Agent 与用户手动操作共享真实项目内容，视图变化不被误认为业务计划已经修改。

## ADDED Requirements

### Requirement: 有限视图命令与真实反馈
Agent MUST 能选中、聚焦、布局有效节点以及打开节点详情，使用稳定节点标识。系统 MUST 在操作完成后返回成功或失败结果，Agent MUST 依据结果报告完成。无效节点或已切换页面上的过期命令 MUST 不修改其他节点。

#### Scenario: 聚焦第三个漫画格
- **WHEN** 用户要求展开第三格且当前页存在该漫画格
- **THEN** 系统选中并聚焦对应节点、打开详情，完成后 Agent 告知结果

#### Scenario: 目标已切换
- **WHEN** 命令发出后用户切换到另一页面
- **THEN** 系统拒绝不属于当前上下文的命令并返回失效结果，不误操作另一页

### Requirement: 当前选择参与理解
系统 MUST 将当前页面、运行、选中节点与其业务标识提供给 Agent。存在唯一明确目标时 MUST 支持“这里”“这个镜头”等指代；多选或目标不确定时 MUST 提问。

#### Scenario: 修改选中镜头
- **WHEN** 用户选中镜头 s002 并输入“这里停顿久一点”
- **THEN** Agent 将 s002 作为修改目标，读取关联计划后调用对应修订任务

### Requirement: 内容修改通过业务工具
系统 MUST 通过与手动编辑一致的业务入口修改 OCR、来源、编排和生成计划，并依据实际产物刷新节点和连线。Agent MUST 不以修改节点显示文本替代业务结果。视图布局变更 MUST 不触发模型或使制作产物失效。

#### Scenario: 调整镜头时长
- **WHEN** 用户要求改变指定镜头节奏
- **THEN** 系统完成实际规划修订及必要审查，成功后画布显示新版本；失败时保留草案和错误，不显示成已通过

#### Scenario: 移动节点
- **WHEN** 用户要求将整列漫画格移到右边
- **THEN** 系统只更新节点位置，不调用制作模型或修改镜头计划

### Requirement: 素材规模与画布结构
整本导入 MUST 以书籍节点和页面选择面板呈现，避免一次展开全书全部页面。选页后 MUST 展示整页节点、按阅读顺序纵向排列的单格以及后续镜头规划与制作节点。手动入口和原有本地成片展示 MUST 保留。

#### Scenario: 展示自动分格结果
- **WHEN** 当前页预处理成功返回六个漫画格
- **THEN** 画布保留整页来源，展示六个有序单格和通向镜头规划的连线，不将首格误作整页
