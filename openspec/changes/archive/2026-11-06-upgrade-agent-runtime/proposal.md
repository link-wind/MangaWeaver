## Why

目前 Agent 依赖完整 JSON 响应，右侧主要展示阶段事件与事后任务记录，缺少逐步回复、连贯的工具过程和持续的专业子会话。上一轮的消息归属、引用与交接记录需要进一步连接到真实的会话执行能力，才能让用户在长制作过程中理解、引导和继续任务。

## What Changes

- 增加真正的模型流式回复，打通供应商、Python JSONL、Electron 和消息界面；保留部分输出并明确完成、中断和失败。
- 将一轮对话组织为有序的公开说明、工具调用、增量进展、工具结果与最终回复，关联已有任务和画布回执。
- 为固定专业角色增加独立、可继续的会话与受限工具循环；沿用三阶段 Creator／Reviewer 产物、提示词和有限审查，不把文件处理包装成 Agent。
- 将当前引导、后续要求、撤回、接收和子 Agent 提问接入活动会话边界，保留固定目标、授权和显式恢复。
- 增加上下文用量展示、可追溯摘要与压缩，替代仅按消息条数截取的主要策略。
- 支持从历史消息编辑后分支、重新回答及切换分支；旧会话和产物保留，分支操作不自动重放制作或重复提交远端任务。
- 默认仍为简洁中文界面：文字逐步出现、工具块可折叠、子任务可展开；不展示原始结构化 JSON 或隐藏思考过程。

## Capabilities

### New Capabilities

- `agent-streaming-conversations`：真实文字增量、有序对话轮次、结束与恢复展示。
- `agent-tool-lifecycle`：工具调用的身份、参数、进展、结果和画布回执。
- `agent-specialist-sessions`：固定专业子会话、受限执行、提问、交回和父子停止关系。
- `agent-active-delivery`：活动会话内当前引导与后续要求的送达、接收及目标归属。
- `agent-context-management`：上下文预算、摘要、压缩及可追溯读取。
- `agent-conversation-branches`：消息编辑／重答形成分支、分支切换及制作隔离。

### Modified Capabilities

无已归档主规范可修改。本次承接 `add-creative-agent`、`unify-agent-task-workflow`、`refine-agent-messages-and-handoffs` 的已实施行为，扩展真实会话能力；已有文件收件、版本引用、Reviewer 判断、授权、停止和防重复提交约束继续有效。

## Impact

- 修改现有模型客户端、Agent 循环、事件和会话存储、专业委派入口，以及 Electron 协议和对话组件；保持现有 CLI 和制作阶段入口可用。
- 以 Manga2Animate `29543daacbf58c609c360bad840649b0de6b4866` 为制作基线，以 Toonflow-app `d7366e36ba30943cf308121c28011b45bbf922e0` 的事件、会话、委派和回复归并为交互参考。
- 扩展项目内文件，不引入数据库、HTTP 服务、通用 Agent SDK、插件／MCP／A2A 系统或任意递归委派。本次所有六项能力均纳入实施，不以增加状态文案替代真实执行。
- 不改变现有供应商和模型选择、图像／视频后端或生成算法。先验证当前配置渠道的真实流式能力，不自动切换模型或把整段返回后逐字播放当作流式完成。
