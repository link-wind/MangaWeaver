## Why

单页工作流在分镜和关键画面增多后占据大量画布空间；整本漫画只能在对话区选取当前页，切换页面还可能重复创建运行。需要在同一画布浏览书籍、展开多页并折叠阶段，保留每页制作进度。

## What Changes

- 漫画分镜、镜头、关键画面与视频阶段可以收成汇总卡；数量、状态和连线同步，展开恢复位置。
- 书籍节点内浏览缩略图、跳页、选择页码范围，按需展开页面；移除对话区重复选页器。
- 多页流程并存，每页可整体折叠；节点标识按运行隔离，选择和对话明确属于哪一页。
- 保存书籍页面到当前运行的对应关系，切回页面复用已有进度；显式新建修订仍保留旧版。
- 运行按钮默认处理当前页，多选后明确顺序运行所选页；浏览、折叠与恢复视图不调用模型。
- 工具栏明确选择分格、脚本、编排、演出、关键画面或视频阶段，对应节点提供阶段运行入口；显式阶段运行复用专业工具，不受对话默认仅本地处理的隐含限制。
- 首页发送后立即进入画布，导入首批只转换 10 页，翻页或指定范围时按需加载；本地导入结果先于 Agent 回复呈现。

## Capabilities

### New Capabilities

- `book-canvas`: 画布书籍浏览、多页流程、阶段及页面折叠与制作目标选择。

### Modified Capabilities

无。已有创作 Agent 与三阶段制作协议继续复用，新能力以增量规范描述。

## Impact

涉及 React Flow 节点投影、画布视图保存、书籍页面浏览、受限 IPC、项目级页面索引及 Agent 上下文与画布回执。无新增依赖、服务、数据库或模型调用框架；MiniMax H3 Lite／480P 及当前渠道阻塞不变。
