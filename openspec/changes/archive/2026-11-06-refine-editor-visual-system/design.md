## Context

现有 `standardize-desktop-ui-components` 已完成 shadcn/Radix 组件迁移和基础 token 收敛；`refine-workbench-visual-design` 已完成多轮轻量化。本轮只在此基础上进一步提升编辑器质感，不重做组件体系。

视觉方向为：克制、专业、流畅。白色主界面，浅灰工作区，紫色只用于主操作和当前选择；漫画、关键帧和视频为视觉主角。参考 Impeccable 的 Operate 原则、Toonflow 的工作区组织和 tldraw／Excalidraw 的画布交互气质；只借鉴交互与层级，不复制代码或品牌。

## Goals / Non-Goals

**Goals:**

- 建立一套可执行的视觉基线，并让首页、画布和对话真实消费这套基线。
- 降低首页和节点的信息密度，突出媒体与生成产物。
- 保证常用窗口、最小窗口、键盘焦点和真实状态的可读性。

**Non-Goals:**

- 不新增组件库、动效框架或设计系统依赖。
- 不改变三阶段流程、Agent 运行时、模型调用、数据协议和项目操作。
- 不重写 `App.tsx` 或现有页面结构。
- 不引入暗色主题、大幅动画或装饰性渐变。

## Decisions

### 1. 以现有 token 为唯一基线

继续在 `theme.css` 扩展语义变量，而不是在页面中写一次性颜色。新增状态色以语义命名，页面只消费语义。字号维持现有 11/12/13/14 层级，避免再发明新字号；标题只保留少量 18/24/28 层级。

间距收敛为 4/8/12/16/24/32，控件高度维持 24/28/32/40。圆角收敛为控件 8、卡片 12、弹窗 14。深度只保留浮层、弹窗和选中节点三档，均使用低强度阴影。

替代方案是引入完整设计系统组件库，但这会扩大迁移范围，且当前 shadcn/Radix 基础已足够。

### 2. 首页改为“创作卡片”而非表单堆叠

首页保留一个主标题，删除重复说明。漫画附件、提示词、添加入口和开始按钮保持在同一 `InputGroup` 视觉容器中，附件使用小尺寸缩略图。最近成片从列表式说明改成媒体优先卡片，标题和日期置于封面下方。

不在首页增加项目配置、模型设置或流程说明；这些仍属于左栏和设置。

### 3. 节点采用四段式结构

节点视觉统一为：顶部类型和状态、中间媒体、下方标题和元信息、hover／选中时的操作。所有业务节点不要求完全等宽，但同类节点宽度必须一致。描述最多保留三行，完整内容走详情。

运行状态使用顶部 3px 细进度条和状态角标；失败详情进入详情或对话记录。缩放小时保留标题和状态，弱化媒体细节和操作；不恢复胶囊形态。

### 4. 对话栏保持现有数据结构，只重构视觉层

右侧对话继续使用现有消息、任务和工具数据，只调整视觉：消息、过程、产物三类内容使用不同密度和背景；工具参数保持折叠；输入框底部固定并内部承载操作。流式输出和阅读位置逻辑不改。

### 5. 验证以实机视觉为主

使用本地离线项目检查首页、素材库、画布、对话、设置和最小窗口。构建和现有回归用于保证代码安全，不新增机械样式测试。截图和验收文档记录真实观察，未验项不勾选。

## Risks / Trade-offs

- [低强度阴影可能让层级变弱] → 保留 1px 边框 + 低强度阴影的组合，只在浮层和弹层使用更强一档。
- [压缩说明文字可能降低新用户理解] → 保留一个主动作和一个空态短句，复杂解释进入设置或详情。
- [节点统一可能影响特殊媒体比例] → 媒体区域按比例自适应，容器和操作区统一。
- [全局 CSS 清理可能影响旧页面] → 每批修改后在常用和最小窗口查看首页、画布和设置。
- [连续鼠标拖动验收仍受工具限制] → 不把键盘分栏验收冒充鼠标拖动验收，实机检查如实记录。

## Migration Plan

1. 先收敛 token 和全局基础样式，清理重复选择器。
2. 调整首页和成片卡片，用现有本地项目检查常用窗口。
3. 调整画布节点、工具条和三栏连续性。
4. 调整对话栏视觉密度，复验键盘焦点和流式历史阅读。
5. 更新设计文档和验收记录，运行构建、现有测试、OpenSpec 严格校验并重新打包。

回滚按批次进行：视觉修改不改变数据格式，可只回退对应 CSS 和组件标记。
