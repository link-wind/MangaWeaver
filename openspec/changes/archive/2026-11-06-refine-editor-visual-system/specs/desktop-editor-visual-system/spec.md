## Purpose

规定 MangaWeaver 桌面工作台在浅色创作编辑器风格下的统一视觉层级、状态语言和关键页面可观察表现。

## ADDED Requirements

### Requirement: 统一视觉基线
桌面客户端 MUST 使用同一套语义色彩、字号、间距、圆角、边框、深度和焦点样式；页面 MUST NOT 为同类控件另建互相冲突的视觉语言。

#### Scenario: 跨页面查看同类控件
- **WHEN** 用户查看首页、素材库、画布、对话栏和设置中的按钮、输入、菜单、弹窗或状态标记
- **THEN** 控件高度、字号、圆角、边框、悬停、选中、禁用和焦点样式保持同一规则，不出现同类控件多套风格

#### Scenario: 状态语义一致
- **WHEN** 等待、运行中、成功、失败、停止或待确认状态出现在节点、对话、任务和提示中
- **THEN** 同一状态使用同一语义色彩和文本说明，用户能通过颜色加文字识别状态

### Requirement: 首页创作启动器
首页 MUST 以创建动画为主要任务，漫画输入、提示词和开始操作 MUST 位于同一个视觉容器中；最近成片 MUST 以媒体封面优先展示。

#### Scenario: 首次进入首页
- **WHEN** 用户打开客户端且尚未选择素材
- **THEN** 首页显示一个紧凑的创作卡片，添加漫画入口、提示词输入和开始创作按钮位于同一容器内，说明文字不超过必要范围

#### Scenario: 浏览最近成片
- **WHEN** 用户已有一个或多个成片
- **THEN** 首页最近成片以视频封面为主视觉，标题、日期和状态保持次要层级，卡片可用键盘打开

### Requirement: 画布节点层级
画布节点 MUST 按类型／状态、媒体、标题／元信息、按需操作组织视觉层级；描述 MUST NOT 挤占节点主视图，长内容 MUST 进入详情查看。

#### Scenario: 浏览普通节点
- **WHEN** 用户浏览画布且未选中节点
- **THEN** 节点显示类型、状态、媒体、标题和简短元信息，编辑和执行操作默认弱化或隐藏

#### Scenario: 查看运行中的节点
- **WHEN** 节点等待执行、执行中或失败
- **THEN** 节点以细进度条或状态角标表达当前状态，错误详情不占满节点主区域

#### Scenario: 查看长描述
- **WHEN** 节点描述超过紧凑显示范围
- **THEN** 节点保留简短线索，完整描述通过详情或节点菜单进入

### Requirement: 工作区连续性
左栏、画布和对话栏 MUST 形成连续的工作区视觉边界；浮层工具条 MUST 与共享组件同一视觉体系，分隔线 MUST 保持贴边且无阴影。

#### Scenario: 打开画布项目
- **WHEN** 用户从首页进入画布并打开右侧对话栏
- **THEN** 三栏边界、背景、工具条和状态色连续，画布媒体不被大面积说明文字或装饰遮挡

#### Scenario: 调整画布缩放
- **WHEN** 用户缩小画布查看整体流程
- **THEN** 节点标题和状态仍可辨识，描述和次要操作按缩放层级弱化，不变成另一种节点形态
