## Context

当前 React Flow 从单个 RunData 构建画布；BookPicker 在对话区，session 仅持有 active_run/active_page_id。select_page 切到另一页时总会创建新运行。节点使用 s001 等局部 ID，不能直接把多页结果合并。参见 proposal.md 的目标。

已复读 Manga2Animate 参考提交 29543daacbf58c609c360bad840649b0de6b4866 的 run_all.py 文件式恢复与现有 Agent tools、画布图投影。继续复用原阶段、任务及审查；本次只扩展页面身份和视图，不修改 MiniMax 调用、H3 Lite/480P 或渠道能力阻塞。

## Goals / Non-Goals

**Goals:** 以少量页面索引与视图数据支持整本画布，保持单页引擎、产物与旧画布可用；浏览和折叠无模型调用。

**Non-Goals:** 跨页联合导演、跨页合成整本长视频、并行付费队列、数据库、工作流框架及多层后端抽象。

## Decisions

1. 页面仍对应已有运行目录。session 记录页面到当前运行的映射，旧项目从 runs 内 input/book.json 补齐关联；显式修订保留来源页面标识。相较重写多页 ProductionPlan，可直接复用所有制作和恢复行为。
2. 书籍节点复用现有缩略图页序，在节点内分页显示及范围展开。仅用户展开的页面建立或复用运行，折叠页面只显示摘要，不读入完整媒体节点。
3. 图投影在现有 graph() 之后组合多页并命名空间化节点，按页面和语义阶段折叠。隐藏节点仍保留业务身份，连线投影到汇总节点，去除内部边及重复边。位置按稳定 ID 保存，不通过横坐标判断分组。
4. 单页视图扩展 canvas.json 可选 view 字段；书籍全局视图保存到书籍目录下的独立视图文件，避免每页覆盖其他页布局。新增字段兼容默认值，不自动重写旧产物。
5. 当前页沿用 active_run，其他展开页只读加载；点击其他页面节点先切换明确目标。对话上下文仅提供目标运行的业务节点，定位隐藏节点先展开并等待真实渲染后回执。
6. 多选运行在客户端依次调用原有单页工具，执行工具栏明确选择的阶段；任何停止、错误或待输入都结束队列。第一版不保存自动恢复队列，重开不继续制作。
7. 显式阶段运行使用本地 Agent 命令直接委派既有专业工具，执行到所选阶段并停止；先验条件不足清楚阻止，已完成阶段复用结果。工具栏显示所选阶段，节点提供同等入口，用户点击明确授权该阶段；普通对话仍沿用输入框的授权范围。
8. 书籍先建立完整文件页序索引，只转换前 10 页及用户请求的页面。CBZ 按成员读取，PDF 按页渲染，MOBI 保留解包结果按需转换（首次仍需解包）；页索引记录本地素材位置。画布先显示导入进度，book.ready 事件保存并发布本地结果，无须等模型回答；翻页每批加载 10 页。

## Risks / Trade-offs

- [多页同名节点或折叠后连线错位] → 页面命名空间与单独图投影检查，记录真实业务 ID 供 Agent 使用。
- [运行事件与用户切换页面冲突] → 区分当前查看页和正在执行的运行，只刷新对应产物；活动执行时不切换制作目标。
- [整本页面过多] → 缩略图分页；只为已展开且未整体折叠的页面读取详细运行，视频保持已有按需媒体机制。
- [旧项目没有索引] → 从现有 input/book.json 和 session 当前页补齐内存索引，选择时保存；不搬迁或重生成原目录。
- [折叠时新增节点] → 汇总来自实时产物，折叠状态独立保存；查看不会触发模型调用。
