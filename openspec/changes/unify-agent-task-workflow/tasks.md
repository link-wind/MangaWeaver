## 2. 统一制作推进

- [x] 2.1 将自然语言委派与单阶段按钮接入同一任务登记和专业执行入口；按钮不伪造自然语言用户消息，不新增总 Agent 决策调用。

- [x] 2.3 将制作范围绑定任务，提供结构化范围扩展操作；连续目标通过审查后自动推进，单阶段目标结束即停。
