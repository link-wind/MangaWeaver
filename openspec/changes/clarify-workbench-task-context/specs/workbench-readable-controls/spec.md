## Purpose

让桌面创作工作台的文字、菜单与标签页易于辨认和操作，同时准确表达成片导航与继续创作入口，在保留白色简约三栏和本地运行方式的前提下减少使用障碍。

## ADDED Requirements

### Requirement: 控件可读且可用键盘操作
工作台 MUST 提供清楚的小字和焦点、中文缩放名称，菜单支持 Escape 与外部关闭，Escape 关闭后恢复触发入口焦点；创作／详情标签 MUST 支持键盘切换，隐藏面板不得继续接受焦点。

#### Scenario: 键盘关闭菜单
- **WHEN** 用户打开更多菜单后按 Escape
- **THEN** 菜单关闭，焦点回到触发按钮

#### Scenario: 切换右栏
- **WHEN** 用户在创作／详情标签按方向键或 Home／End
- **THEN** 在可用标签之间切换，选中状态、焦点与显示面板一致

### Requirement: 成片导航准确
全局成片列表 MUST 使用成片库名称，仅列实际已有视频的记录；打开名称 MUST 继续进入其所属项目，保留实验限制。

#### Scenario: 草稿与成片并存
- **WHEN** 本地同时存在规划草稿、模拟结果和实际成片
- **THEN** 成片库继续只展示符合原有成片规则的记录

### Requirement: 已打开项目可直接继续
首页 MUST 在已有可继续项目时直接返回其画布；没有项目时提供打开项目入口。继续操作不得启动模型或丢失当前上下文。

#### Scenario: 从首页继续
- **WHEN** 用户在已打开项目的首页点击继续当前项目
- **THEN** 回到原画布，不再选择文件夹，不启动制作
