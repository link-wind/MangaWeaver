## Purpose

帮助用户在项目级创作对话中辨别任务所属漫画页或独立运行，并清楚区分连续制作、单阶段操作和对话授权，以真实协作记录提供简短、可追溯的进度说明。

## ADDED Requirements

### Requirement: 任务显示真实归属
工作台 MUST 为制作任务显示可核实的文件页或运行归属，不将当前页码套用到历史任务；项目对话历史 MUST 在切页后保留。

#### Scenario: 当前页与历史任务不同
- **WHEN** 当前页待处理而另一页已有完成任务
- **THEN** 历史卡显示其真实页码，定位操作仍指向该任务

#### Scenario: 来源不明确
- **WHEN** 历史任务没有可核实的页映射
- **THEN** 显示已知运行名或历史运行，不伪造页码或隐藏任务

### Requirement: 制作与对话目标明确
工作台 MUST 区分当前／所选运行的连续制作终点、节点单阶段执行及对话能力权限；选择节点 MUST NOT 隐式扩大权限或更改批量选择。

#### Scenario: 选择节点后制作
- **WHEN** 用户选中一个节点并查看制作与对话入口
- **THEN** 顶部显示制作范围和终点，节点提示单阶段，对话框显示目标及对话权限

### Requirement: 协作摘要简短可追溯
任务 MUST 默认展示短结论和真实角色关系，并允许展开轮次、审查依据和完整内容；问题、修订结论及恢复入口 MUST 可达，不为摘要调用模型或捏造通过及问题数。

#### Scenario: 审查退回后通过
- **WHEN** 已有记录包含审查退回与后续修订
- **THEN** 默认卡呈现实际当前结论，展开后能分辨角色、轮次和各轮反馈

#### Scenario: 查看历史与切换详情
- **WHEN** 用户正在阅读旧记录或切换创作／详情
- **THEN** 已展开内容、草稿和引用保留，新事件不强制跳走历史阅读位置
