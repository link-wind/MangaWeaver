## Why

Impeccable 评审发现，当前页与项目历史任务容易混淆，制作入口和对话权限需要用户自行辨别，小字与菜单键盘行为也影响操作。依据 `docs/WORKBENCH_UI_IMPROVEMENT_PLAN.md`，在既有白色三栏界面上做必要修正。

## What Changes

- 制作任务显示真实来源页／运行，项目级对话与当前操作目标分开表达。
- 区分连续制作、节点单阶段操作与对话权限；精简协作摘要，保留角色、轮次、审查依据与恢复入口。
- 提高小字可读性，完善菜单 Escape／外部关闭／焦点恢复、标签键盘切换与中文缩放标签。
- 将项目库准确命名为成片库，已有项目可直接继续；保持列表仅显示成片。

## Capabilities

### New Capabilities

- `workbench-task-context`: 任务归属、制作入口和多 Agent 协作的上下文展示。
- `workbench-readable-controls`: 清楚可读、键盘可操作的工作台控件与成片导航。

### Modified Capabilities

无。主规范目录尚无对应能力；既有已完成变更保持不动。

## Impact

仅改桌面 React 展示、少量辅助函数、样式和文档，沿用现有会话与任务数据。不改模型、供应商、生成协议、阶段算法、权限或恢复机制，不增加依赖与服务。验收用已有记录和本地模拟，不自动调用付费模型。
