## Purpose

保护本地桌面工作台的退出、停止和媒体读取边界，使渲染故障或任务竞争不会使应用永久卡住、误报完成结果或遗留本地子进程，并在媒体无效或越过授权范围时提供可理解的错误。

## ADDED Requirements

### Requirement: 有限退出与准确停止
客户端 MUST 在保存回执缺失或渲染崩溃时仍能有限退出；已完成任务 MUST 保留完成结果，协议错误 MUST 清理本地任务进程组。

#### Scenario: 渲染层无法回应关闭
- **WHEN** 用户关闭窗口而渲染层不再回应
- **THEN** 客户端停止需要停止的本地任务，有限等待后退出，不无限阻断。

#### Scenario: 完成先于停止
- **WHEN** 引擎已发出完整完成事件后用户触发停止
- **THEN** 已完成结果保留，不被改报为中断。

### Requirement: 媒体授权与空文件诊断
客户端 MUST 将媒体访问限定在运行目录与明确授权的来源；空媒体 MUST 返回可诊断错误。

#### Scenario: 清单引用越界文件
- **WHEN** 运行清单引用未授权目录或指向该目录的符号链接
- **THEN** 不能通过读取清单获得该文件的访问令牌。

#### Scenario: 零字节媒体
- **WHEN** 用户预览零字节图片或视频
- **THEN** 显示媒体为空的明确错误，不把它静默当成普通404。
