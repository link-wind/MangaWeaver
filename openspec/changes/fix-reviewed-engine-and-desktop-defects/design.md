## Context

重新阅读 Manga2Animate 固定提交 `29543daacbf58c609c360bad840649b0de6b4866` 的 `run_all.py` 与 `generate_storyboard.py`：继续沿用阶段、候选文件和显式恢复。本轮缺陷主要在新增桌面层，参考实现没有对应的 IPC、项目锁和退出流程。

## Goals / Non-Goals

只修复已核实边界，不重写制作流程，不增加自动换模型、通用调度器或大规模测试。H3 模型与分辨率选择不变；验收使用本地样例，不提交付费请求。

## Decisions

- 候选文件名使用完整匹配，状态 sidecar 不算候选；真正损坏的候选继续明确报错。
- 运行锁保留 flock，使用上下文内的已持有路径识别同一调用链重入，其他线程／进程仍竞争系统锁；不增加全局锁服务。
- 草稿清理仅在提交带有画布读取版本、当前版本与文本都相符时执行；不因繁忙阻塞收件。未提供版本则保留草稿。
- 模型 JSON 校验异常继续作为执行失败；用户范围不明确才进入待决策。审查耗尽使用轻量异常类型传递原因。
- fork 将当前保留关键画面复制到新目录，保留内容哈希和审查来源；不复制旧视频任务或伪造新的通过记录。
- 退出只等待一次保存回执，超时允许退出；退出前仍保留已有活动任务提示，渲染故障时停止本地任务后退出。正常完成事件先于停止标记，协议错误使用现有进程组清理。
- hydrateRun 只授权运行目录和用户明确选择的目录／文件，符号链接用 realpath 检查；不通过任意 JSON 扩大授权。
- 完成的 OpenSpec 变更按实际增量同步并归档，未完成变更保持原状。现有成果与本轮修复分组本地提交，不推送。

## Risks / Trade-offs

- [保存回执超时可能保留上次已落盘草稿] → 尽力保存后有限退出，不无限卡住应用。
- [历史外部素材] → 允许已明确选择的来源；其余清楚报告未授权。
- [fork 占用额外磁盘] → 只复制保留的关键画面，不复制视频或全目录。
- [历史规范重叠] → 对照实现按时间同步，不用未完成提案覆盖现状。
