## Context

见 proposal.md。现有 React 工作台已使用 JSONL 对话事件和项目任务账本。`CreativeTimeline` 将文字、子会话、工具、任务书和回报同时呈现，`CanvasWorkspace` 在单击时打开独立详情层，`App` 左栏混合全局成片与项目素材。现有拖动、书籍十页加载、引用、停止及授权均保留。

制作机制继续依据 Manga2Animate 固定提交 `29543daacbf58c609c360bad840649b0de6b4866`；本轮复读项目 `docs/REFERENCE.md` 与现有制作入口，UI 增量不改其专业流程，也不触碰 H3 能力检查或默认模型。专业角色事实仅来自已有事件与任务，不新增推理或虚构互聊。

## Goals / Non-Goals

**Goals:** 减少展示重复；把角色协作放在明确任务下；使主要操作范围可见；让画布与创作输入占据合适空间。

**Non-Goals:** 不变更后端协议、生成算法或自动重试，不换框架，不删除历史或通用重写工作流。界面走查不自动启动付费模型。

## Decisions

1. 对话增加少量纯展示投影函数，将父工具、专业角色与任务按现有身份归组，保留实际顺序。优先使用任务事实摘要，角色活动按需展开；原始事件留在技术详情。比单纯用 CSS 隐藏重复文本更能保持问题、恢复操作与审查依据可达。
2. 任务失败使用简短中文原因；完整错误在详情中。画布级同一任务异常不重复显示全宽横幅，导入、环境、文件等全局错误仍正常提示。不能通过删错误记录达到精简。
3. 右栏使用创作／详情两个视图，共享既有节点选择和草稿状态。创作组件保持挂载，避免切换丢流、折叠状态和滚动位置；未回答问题在标签处提示。单击只选择，双击及原画布 open_details 命令打开详情并维持回执。
4. 顶部明确显示当前文件页或所选页及运行终点，保留原 onRun／onStop。节点快捷运行通过悬停与键盘焦点呈现。输入范围改为“仅对话／规划／关键画面／成片”，其底层权限值不变；不将“仅对话”误标为完全离线。
5. 输入框默认三行并自动增长到有限高度。加号菜单直接选加入目标或参考，传递用途参数后调用原 capture_references，不依赖异步 setState 后立即读取旧用途。队列送达方式仅运行时出现。
6. 左栏以项目为上下文，书籍页码按十页组提供可达入口，已展开页使用原 onActivate，未展开页使用原选页／打开操作。所有实际加载仍由既有后端处理。全局成片留项目库；项目文件、导入运行及模拟通过明确菜单保留。
7. 浅色与少量紫色沿用已确认方向：系统中文字体，正文约 13px、辅助文字 11–12px、8px 基础间距；控件约 32px 高，卡片约 10–12px 圆角。分隔线无阴影。保留现有 logo 图标，不新增插画、渐变或装饰模块。清理被替换的对话样式，少量共用 CSS 变量统一组件。
8. 默认目录约 220px、右栏约 360px；已有手动保存宽度不重置。小地图默认关闭。页面首次可用时适配该页一次，刷新与用户拖动不触发自动适配，不覆盖已保存节点位置。

## Risks / Trade-offs

- [归组隐藏必要事实] → 问题独立常显，恢复操作留在任务摘要，审查与参数按需可查；少量独立映射检查及历史项目走查。
- [切详情丢草稿或错过问题] → 保持创作组件挂载并保留明确未答提示；切换只改变展示。
- [精简引起意图／授权变化] → 引用用途显式传参，范围沿用原值，节点／顶部复用同一执行入口。
- [旧样式覆盖新布局] → 使用工作台作用域和统一变量，逐处替换旧样式，不重写无关来源编辑器。
- [验收干扰正在运行任务] → 先只读检查，客户端空闲后更新；验收仅使用本地历史与模拟任务，不停止用户活动制作或自动付费重跑。

## Migration Plan

仅升级前端包。会话、任务、书籍、产物和面板宽度不迁移；回退旧前端不会删除本轮前端优化产生的视图数据。完成构建和本地原生走查后再替换客户端包，不自动归档其他 OpenSpec 变更。
