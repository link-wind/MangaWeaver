# 客户端创作演示

首页「体验演示」使用这一组本地素材，复用现有模拟任务、JSONL 事件、任务账本和画布消息。每次创建独立的 `results/simulations/` 运行，不读取或改写其他创作项目。

素材来自用户提供的《入间同学入魔了》第1卷印刷页94，以及此前该页测试的关键画面和视频。漫画及角色权利归原权利人所有；素材仅用于本项目界面体验与验证。本轮未生成新媒体。漫画分格、规划、Creator／Reviewer 活动和公开回复按预设顺序回放，界面明确标注为本地演示。

流程：整页 → 6格漫画 → 来源脚本 → 4镜头编排（含退回修订）→ 演出 → 彩色关键画面 → 4个已有视频片段 → 视频审查暂停。此时可查看反馈、定位镜头或查看协作；再次点击「继续演示」显示已有整页预览。支持停止后继续。

镜头03的历史视频问题仍保留；继续演示不会模拟修订通过，预览不能作为合格成片。片段保留原生音轨，整页预览保留此前日语配音和中文字幕。输入框在演示中只读，不调用模型、上传或远端接口。模拟文字的逐段追加用于演示阅读节奏，不代表一次真实 SSE 模型请求。

`production.json` 中路径均相对于当前目录；不包含密钥或用户绝对路径。正式创作请返回首页导入自己的漫画。
