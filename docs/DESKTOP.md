# MangaWeaver 桌面工作台

桌面入口使用 Electron + React + TypeScript + Vite，复用现有 Python 三阶段与 Creator／Reviewer 流程。首版面向 macOS，Python、FFmpeg 和模型凭据仍由本地环境提供，不捆绑 MAGI 权重。

## 当前工作区

首页从“添加漫画”菜单选择本地漫画或素材库；成片卡片可播放，点击名称打开所属项目。素材管理先预览，再点“用于创作”。整本在画布书籍节点勾选页面或输入范围，点击明确的展开按钮；左栏只保留当前页与跳转。

项目以画布为主。右上角选择制作终点后运行；节点按钮只执行对应阶段。“画布更多操作”可进入分格、规划、视频任务与结果，专业视图用“返回画布”回到当前工作对象。视频任务页的“查询并下载”用于已有远端任务，不重新提交。

分格编辑可切换浏览选择与绘制分格，选中格校正对白，坐标默认折叠，保存为新来源版本。候选用缩略图预览，正式采用仍需原审查校验。设置中可单独更改一个本地路径，取消保持原配置。

本轮代码与实机验收边界见 [全客户端体验统一记录](DESKTOP_EXPERIENCE_VALIDATION_2026-11-03.md)，未完成完整客户端验收。

## 启动与构建

在项目根目录创建 Python 环境并安装 `pip install -e .`，准备 FFmpeg。然后：

```sh
cd desktop
npm ci
npm run dev
```

生产界面与桌面代码：`npm run build`，启动：`npm start`。未签名 macOS 应用：`npm run pack`，产物位于 `desktop/release/mac-arm64/MangaWeaver.app`（随当前架构变化）。当前构建依赖开发机 Python，移动应用后需重新选择项目根目录和环境。

右上角“本地环境”可依次选择引擎项目根目录、Python 可执行文件、FFmpeg 可执行文件和 `.env`。不需要在界面输入密钥。设置保存在 Electron 用户数据目录；页面仅接收白名单配置与凭据是否存在。默认 H3 Lite / 480P 不变，渠道不支持时阻止提交。

## 使用

当前界面以首页和画布为主，以下早期分阶段页签说明作为历史记录保留。最新入口：

2026-11-01追加：全局成片入口改称“成片库”；已打开项目可以直接继续。任务卡标注来源页／运行，顶部“开始制作”选择终点，节点快捷操作只执行单阶段，输入框的“对话权限”保持原授权值。菜单支持Escape关闭，创作／详情支持方向键切换。验证及新版应用位置见 [任务上下文修改验收](WORKBENCH_CONTEXT_VALIDATION_2026-11-01.md)。

1. 首页添加单页或整本漫画、输入改编要求，点击“开始创作”。项目菜单提供打开项目和导入已有运行；本地示例在首页加号菜单中。
2. 左栏查看当前项目的漫画页、独立运行和成片。书籍按十页一组浏览，也可直接输入文件页码。首页与项目库只列已有成片，点击名称直接打开所属项目。
3. 画布单击选择，双击打开右栏“详情”；切回“创作”保留草稿、引用和对话。输入框加号可明确加入目标或参考；制作范围决定对话可执行到哪一步。
4. 顶部“做到”选择制作终点，再点击“运行”；节点上的快捷按钮只执行对应阶段。运行中同一入口变为“停止”，保留已完成进度。分隔线可拖动，小地图在更多菜单中按需显示。
5. 对话按任务显示简短摘要，展开“协作过程”查看 Creator／Reviewer 的审查与修订；问题和恢复入口直接显示，原始参数与错误在“技术详情”内。

本轮实现与客户端验收见 [界面优化验收记录](WORKBENCH_UX_2026-11-01.md)。

### 早期阶段入口说明

1. 新建或打开项目，或直接“打开已有运行”。打开结果不会调用模型。项目用 `project.json` 索引来源和运行，既有 `results/` 可外部挂接。
2. 素材页导入 PNG／JPEG／WebP 页面，拖动框选矩形；列表中校正阅读顺序、坐标、对白和说话人。保存产生新来源清单；说话人与正文合并保存至既有 `Panel.text`，不扩展引擎来源协议。自动分格是显式 MAGI 操作，OCR 使用配置指定的本地后端，缺失依赖或权重时直接报错。
3. 生成页新建运行并导入来源清单，再启动规划。镜头列表显示静态／动作分类、来源格和时长，详情展示关键画面、时间锚点和审查。文本反馈指定脚本、编排、演出或关键画面阶段，交由原有循环处理；该操作可能调用付费模型。
4. 已有视频任务的运行不接受规划改写。修改来源或生成输入时新建运行，再选择来源重新规划；不复制旧视频任务。源素材修改不会改变旧输入。
5. 生成任务预览使用 dry-run，不提交模型；正式生成按钮明确标记付费。恢复只查询／下载已有任务 ID，不重新翻译、评审或提交；下载完成后若需继续审查和导出，显式执行生成流程。未知提交状态必须先在平台核查。
6. 结果页切换候选、干净版、字幕版，播放原生音轨，查看字幕与审查记录并导出既有视频或 SRT。拒绝结果可导出预览，状态保持拒绝。

停止仅中断本地执行，远端视频可能继续生成。退出时如有本地活动任务，可选择继续运行或停止后退出。CLI 与桌面使用同一运行锁，进程退出后自动释放。

## 复用与限制

参考 Manga2Animate 提交 `29543daacbf58c609c360bad840649b0de6b4866` 的 `run_all.py`、`create_video.py`：保留文件式阶段恢复与审查机制；不迁入原源码。桥接直接调用 `cli.execute`，共用配置快照和来源签名；事件在阶段边界输出，不解析日志。

- 正式运行映射：`source/manifest.json`、`planning_state.json`／`planning_draft.json`、`production.json`，`iter*/selected.json`／`draft.json` 作为历史规划版本；`video/*/*/tasks.json` 对应候选任务。
- 历史整图参考实验 `EXPERIMENT.json` 标记只读；可看媒体、视频审查和报告，不承诺支持实验脚本的重新执行。
- 视频任务恢复不等于付费生成流程的任意断点自动续跑；不会绕过拒绝审查。
- 现有 MAGI 转录缺少逐格关联时，界面显示已有总转录，逐格对白由用户显式校正。
- 首版支持矩形裁图和文本反馈，不支持多边形编辑、镜头表直接拖改、完整剪辑时间线、ASR、TTS 或混音。
- 正式字段缺失显示尚未生成；外部引用失效时使用文件选择器重新挂接。原始 JSON 是业务事实来源，没有额外数据库。

实现协议、授权媒体、互斥和验证记录见代码及 OpenSpec `add-desktop-workbench`。

## 首页本地预览

首页和项目库自动扫描工作目录的 `results/`、当前项目运行目录及本次会话选中的扫描目录。也可点击“扫描目录”选择其他位置，刷新按钮重新读取。仅识别带画布、规划检查点、生产清单、实验标记或来源清单的运行，最多向下查找两级；识别后不再把其子目录当作其他运行，媒体扫描不跟随符号链接。

卡片显示已有 `final.mp4` 或 `preview.mp4` 并可原地播放；没有成片时显示关键帧或漫画封面。点击名称进入原画布，实验记录保留实验标记。扫描只读本地文件、不请求模型、不修改审查结果。

首页与自动扫描列表只显示运行根目录已有 `final.mp4` 或 `preview.mp4` 的记录；规划草稿、仅关键帧或未完成的测试记录不展示。手动打开运行仍可继续未完成创作。

本地分格与逐格 OCR 已实测，画布新增“自动分格”入口、真实处理阶段和完成后返回画布；详见 [本地预处理](LOCAL_PREPROCESSING.md)。

## 画布运行与进度（2026-10-27）

画布右上角“运行”按输入框已选制作范围继续当前项目。仅本地处理时直接执行分格／OCR；允许规划、生图或完整制作时由已有创作 Agent 读取当前进度并委派阶段任务。运行期间按钮变为“停止”。已通过的产物沿用原有恢复规则，模型与视频渠道约束不变。

每张卡片顶部有细进度条：处理时滚动、完成后填满、失败或审查拒绝时标红。引擎未提供可量化进度，因此执行中不显示估算百分比。初始仅显示真实输入；分格、镜头、关键画面与视频随真实阶段和已保存产物逐步出现，不预建全部未来节点。新产物刷新保留已有节点位置和输入草稿。

对话栏显示带时间的阶段与工具记录、完成状态和失败原因。桌面事件写入运行目录和 Agent 项目目录的 `runtime_events.jsonl`，重开可查看最近记录；查看操作不写日志、不触发制作。异常退出而没有终止事件的历史记录显示中断，不保持加载动画。原有模型反馈、审核与文件恢复机制不变，仅增加阶段检查点发布。

验证：19 项 Python 检查、6 项桌面检查及生产构建／macOS 打包通过。真实漫画页离线完成 MAGI 分格与 OCR，画布数据由 1 张原页增加为原页＋6 格，记录可重读；已在打包应用确认运行按钮、制作范围提示和细进度条。本轮新增付费调用为 0。验证产物位于 `results/canvas-runtime-validation-20261027/`。

## 模拟任务

首页点击“模拟任务 · 免费”，进入独立的模拟画布，再点右上角“运行”。约 35～40 秒内，按顺序显示 3 格漫画、来源脚本、2 个镜头、4 张关键画面、2 个视频任务与最终模拟预览。可拖动、缩放、选中卡片并查看运行记录；中途点击“停止”，再点“运行”会从已完成的步骤继续。完成后回首页可创建新的模拟任务。

示例来自 `examples/cross-panel/`，分格和规划均为预设数据，FFmpeg 仅生成本地静帧预览，不代表 AI 动画质量，也不进行真实 MAGI 推理或模型审查。模拟画布显式标记，不调用 API，不需要凭据；真实制作与 Agent 入口在模拟任务中禁用，模拟结果不进入首页成片列表，不写 `production.json`。

每次模拟保存在 `results/simulations/<id>/`，使用同一 JSONL 事件、卡片刷新、进度条、运行记录与停止机制。`simulation.json` 只记录已完成步骤，原有正式运行不变。完整本地模拟、停止续跑与网络阻断验证通过；当前共 20 项 Python、7 项桌面检查通过。


## 本地环境设置

左下角「设置」打开设置弹窗，集中显示项目目录、Python、FFmpeg 目录和 `.env` 路径。通过「本机环境／关于」切换内容，关闭按钮、Escape 或点击遮罩回到原画布或页面。侧栏收起后保留设置图标。每行「更改」只选择并保存该项路径，取消不会改动现有配置。密钥不在界面展示。

「重新检测」只读取本机依赖与配置状态，不调用付费模型。运行任务期间禁止更改路径与重新检测；可查看设置。返回后保留原画布和草稿。本版仅配置本地环境，不包含模型渠道或生成参数。


## 漫画素材库

左栏「素材库」是独立的本地漫画书架，只有点击「导入漫画」并选择文件后才收录。支持 MOBI、PDF、CBZ、PNG、JPG、JPEG 和 WebP；不扫描其他目录，也不自动收录已有项目或首页临时添加的漫画。

原文件副本、分页缓存与索引保存在客户端用户数据目录的 `materials/`，不依赖某个制作项目。封面取第一页缩略图；复用原有漫画导入机制，首批仅加载10页。同一文件按内容指纹去重，导入不会调用模型。

首页输入框内点击「素材库」，选择封面上的「添加到创作」，会返回首页并保留提示词、显示漫画名称和封面。也可以从左栏书架直接添加。此操作只选择素材，不自动生成；点击「开始创作」后才进入原有整本分页／选页或单页流程。

## Toonflow 借鉴优化

首页“从素材库选择”以弹层打开同一书架，取消后回到原输入。画布左上角可搜索已加载节点；选中节点后在右侧详情中查看长文本、协作记录和关键画面候选。草稿可单独保存，制作仍需显式启动。

节点支持右键菜单，也可先聚焦节点再按 Shift+F10。可将右键节点添加到对话作为修改目标、用作参考、查看详情或折叠节点。引用仅加入草稿，不会自动发送消息。

「删除节点」与「删除后续节点」均先弹窗确认，列出实际待删除文件及关联记录。删除会永久清理对应生成结果及依赖的下游产物，无法恢复；原始漫画页、整本漫画、input/ 和素材库保留。删除后续保留当前层及其上游；折叠列按业务身份清理，不波及其他页。部分镜头或画面删除后撤销完整计划、保留待审草案，需显式重跑。整段对白、合并任务表、字幕和成片作为共享产物随依赖清理。远端已提交任务不会取消，删除本地记录后不能继续本地查询。运行中、实验或模拟运行禁止删除；取消不写入，产物变化需重新确认。旧隐藏状态不再应用，不提供删除恢复入口。

保存遇到外部修改时会保留草稿并阻止静默切换；“重新读取”需要确认放弃本地修改。候选预览不会替换当前产物，只有来源一致、审查通过且没有下游视频任务的合法候选可直接采用；其余按显示原因进入原修订流程。

本轮实施与未完成的客户端检查见 [验收记录](CREATIVE_WORKBENCH_VALIDATION_2026-11-03.md)。

整本漫画的左侧目录采用紧凑导航：显示书名、总页数和当前页，支持前后翻页与输入页码跳转。首次按需加载的 10 页不再逐项占据左栏；完整选页继续使用画布书籍节点。
