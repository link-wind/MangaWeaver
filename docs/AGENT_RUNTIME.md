# 创作 Agent 会话

打开项目，在右侧输入要求即可。解释问题只产生文字回复；制作按输入框所选范围执行，也可以用画布上的阶段运行按钮。

## 对话与协作

- 回复直接读取模型增量，不在完整返回后模拟打字。工具参数完整校验后才执行。
- 一轮中的说明、工具、专业角色和结果按顺序显示；工具详情默认折叠。提交远端、保存文件与审查通过是不同状态。
- 脚本、编排、演出以及专业评审拥有独立的角色上下文。Creator 提交候选，Reviewer 继续使用原来的结构化结论；原有限反馈和候选选择仍有效。
- 专业角色需要信息时会提出问题。在原分支的输入框回答，系统将答案送回对应子会话，再继续原任务。
- 生图、视频、裁图和拼接继续使用原工具。图片生成器本身不新增文字策划模型；本次未重写图像／视频生成算法。

## 运行中补充与停止

“调整当前任务”在下一安全边界处理，不会改变已提交请求。影响产物的要求继续走显式修订和审查。“稍后处理”会排队，在当前任务正常完成后建立独立任务；尚未接收时可以撤回。失败、停止或等待回答时不自动执行队列。

点击停止会中断本地活动请求和专业子调用，保留已收到文字与任务记录。远端视频是否能取消以接口实际能力为准，原任务 ID 保留。重开项目只读取历史，不自动发起付费制作。

## 上下文与分支

右栏顶部可查看本地上下文估算和渠道返回的实际用量，两者分开显示；未知的模型容量不会显示为精确百分比。长对话在活动任务内按预算压缩，也可手动“压缩历史”。摘要保存来源范围，原记录不删除；失败不会静默丢弃历史或换模型。

`AGENT_CONTEXT_BUDGET=32000` 为可调整的本地文字输入预算，不是模型容量或计费 token，也不包含媒体 token。

历史用户消息下的“编辑”或“重新回答”创建新方案，顶部菜单切换分支。原对话、产物和任务记录保留，新方案不会重放旧工具或沿用旧付费授权。新分支首次回复默认仅文字；需要制作时，在当前分支明确选择范围后发送要求。活动任务须先停止或完成，再切换分支。

## 实现与当前边界

继续使用 Python JSONL → Electron → React。项目内的 `conversation.jsonl` 保存有序会话事件，`agent_sessions/` 保存分支与固定角色会话；`session.json`、`tasks.json` 和 `pending_requests/` 保留原职责。首次升级会备份既有会话／任务文件。不新增服务、数据库或 Agent SDK。

当前实际验证渠道为幻灵 `gemini-3.8-flash` 的 native／curl 流式入口。Gemini 客户端也实现显式兼容接口和 SDK 流式读取，但本轮未对所有渠道作真实验证；尚未适配流式的 Kie／词元对话入口会明确报错，不自动换模型或伪装成流式。既有 CLI 制作调用仍可使用原 JSON 入口。

验证范围与证据见 [客户端验收记录](archive/validation-2026-11/CLIENT_AGENT_RUNTIME_2026-11-01.md)。

## 流式连接错误（2026-11-01修正）

旧版在curl未收到HTTP响应头时，会将初始状态值0误报为“流式接口 HTTP 0”，丢失连接故障原因。现区分真实HTTP错误与curl传输失败：未收到响应头、接收途中断开分别说明，保留安全的curl错误码，不输出可能含凭据的原始stderr。代理CONNECT及临时1xx响应不当成最终响应。

例如curl 7表示连接失败，28表示连接或响应超时，18表示响应数据不完整。真实503等错误仍走原有限重试；连接错误与部分流不自动重交，不换模型或接口。部分动作仍须完整校验后才能执行。

本地HTTP场景已验证响应头前超时、SSE部分接收后断开、103后正常SSE及真实503；没有为这次修正重发付费模型请求。历史“HTTP 0”日志未保留curl退出码，不能仅凭旧记录断定具体故障；后续显式恢复请求会使用新处理。

## 子 Agent 公开文字显示（2026-11-01修正）

界面精简时，专业 Agent 的增量文字被归入协作过程，却未在默认运行卡片中显示，造成“没有流式输出”的观感。现将当前任务最新的公开说明直接显示在运行卡片内，随真实增量事件追加；任务完成后，文字保留在可展开的协作过程中。历史运行卡片不跟随新任务显示为实时输出。

流式仅展示模型主动返回的公开说明，不显示隐藏推理或未完成的结构化参数，不用前端逐字动画模拟模型输出。实际日志中一次脚本说明分3段、约0.27秒返回，因此上游短文本集中返回时仍可能很快显示完整。

回归检查覆盖任务完成前的逐段更新及完成后的文字保留，前端22项检查通过。独立客户端使用明确标注的离线事件验证：第一段在任务结束前可见，第二段在同一卡片直接追加。本次未调用付费模型，离线事件间隔不代表真实渠道速度。
