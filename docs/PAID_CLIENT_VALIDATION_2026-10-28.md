本轮通过原生 MangaWeaver 客户端完成关键画面、日语对白、H3、视频评审、字幕、成片播放与文件导出。总 Agent 的画布定位及回执也已实测。来源脚本与镜头编排复用同一测试项目中此前由真实模型生成并通过审查的产物；它们最初经 JSONL 后端启动，不宣称本轮从首页重新执行了所有规划。

项目：`results/paid-e2e-20261027/`；运行：`runs/page012/`。原漫画为第 12 个文件页，四格，规划为三个静态对话镜头，目标总时长 12 秒。候选数均为 1。

## 测试发现及修复

1. macOS 原生选择器解析 Python 符号链接，把虚拟环境解释器变成系统解释器。新增 noResolveAliases，重新选择后保存路径确认为项目 .venv/bin/python，客户端环境检查通过。
2. 本机 Python TLS 访问幻灵反复报 SSLV3_ALERT_BAD_RECORD_MAC。为图片和 H3 提供显式 curl 传输，视频评审沿用已选择的 curl；保留 TLS 校验，不自动切换渠道、模型或重交付费任务。
3. 图片生成成功后的下载失败无法恢复。渠道响应现在在下载前保存，received 状态仅恢复原图下载。第一张实际付费图片从原下载异常中的确切 URL 恢复，记录来源事件；没有再次生图。
4. 未完成检查点被当成已结束轮次跳过，导致空的“轮次上限”错误。已通过的中断检查点现在继续当前轮，保持原输入反馈和防重记录；真正未通过的审查仍进入下一轮。
5. 视频评审原先 180 秒超时不足。本轮三次成功视频理解分别耗时 227.90、199.93、270.82 秒，视频请求等待时间改为 300 秒，文本仍为 180 秒，并记录失败传输耗时。
6. curl 配置中的中文 JSON 转义被错误处理。保留 UTF-8 文本，检查过中文、换行、引号与特殊字符的实际接收内容。
7. 并行提交的视频只把当前查询的一段显示为运行中。现在按已保存的远端任务状态显示其他已提交候选；本轮未额外付费重生成验证该显示，使用对应回归用例和构建检查。
8. Agent 将计划 12 秒误报为实际时长。状态现在携带 export.json 的实际时长，系统提示明确区分；客户端再次提问已验证回复 13.375 秒。
9. 本机旧字幕字体路径失效，已修正为现有 STHeiti Medium.ttc，并通过实际中文字幕导出及抽帧核对。
10. 重开客户端后，首页原扫描深度没有覆盖 results/项目/runs/运行目录，漏掉本次成片。扫描增加一层，实际扫描已发现本次成片，结果共 6 部；仍只显示有成片的记录。

## 费用与边界

本次生成 3 张图片、3 段视频。图片 Key 的累计成功请求从 36 到 39、累计费用从 0.72 到 0.78；视频 Key 从 15 到 18、累计费用从 6.48 到 7.44。平台标注 USD，分别为图片 0.06、视频 0.96，未换算人民币。这不包含所有规划、对白、Agent 和评审文本费用，不能当作完整总价。原始用量文件保存在测试项目中。

两次初始图片 TLS 失败和初次 H3 TLS 失败均先核查渠道成功请求与计费记录，再保留错误记录并从客户端明确重试。图片恢复与视频恢复使用原产物／原任务 ID。

用户仅本次允许标准 H3／768P。客户端环境已恢复原项目 .env，默认仍为 H3 Lite／480P，独立测试 .env 保留供明确恢复本次运行使用。渠道的 Lite 接口限制没有被本次标准版测试证明已解决。

这是静态对话样例，不代表复杂动作、首尾帧分段接缝或整本连续制作已通过。多次锁屏曾中断界面操作，用户授权临时保持唤醒；测试结束后已撤销，不修改长期系统设置。
