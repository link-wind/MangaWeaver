# 创作 Agent

流式对话、专业子会话、运行中消息、上下文压缩和分支的最新用法见 [Agent 会话](AGENT_RUNTIME.md)。

首页添加 MOBI、PDF、CBZ 或单页图片，输入要求后发送。首次使用先选择项目目录。首页与画布使用同一个项目会话，原来的手动按钮继续保留。

首页点击本地成片记录会直接打开所属项目并进入该运行的画布。旧生成目录没有项目索引时，原地补充 `project.json`，将原运行登记为 `.`；旧图片、视频、输入签名与远端任务记录不迁移、不重写。后续修订仍保存在项目 `runs/` 下，打开记录不调用模型或自动制作。

整本先本地拆页，Agent 询问文件第几页。文件页序从 1 开始，包含封面、目录，与印刷页码可能不同。书籍节点内可点击缩略图或输入 `2-4,8` 范围，再点击“展开”，在同一画布展示多页流程；单页展开也会切换当前页。单页图片直接选择。整本不会上传给模型，仅按需发送当前页面。

画布输入框可以表达“自动分格”“展开第三格”“把选中镜头的停顿延长”。当前选择会传给 Agent；业务修改仍通过原有修订与审查，视图命令通过前端回执确认。Agent 对话调用模型、可能计费；输入框的制作范围默认仅对话和本地处理，可明确允许规划、生图或完整制作。

## 组成

- `agent/loop.py`：结构化动作循环，读取真实工具结果，回答、提问或继续执行。
- `agent/tools.py`：固定素材、制作和画布工具；专业委派使用原规划流水线及 Creator／Reviewer。
- `agent/workflow.py`：对话与阶段入口共用的目标推进、专业任务交接、修改与恢复。
- `agent/tasks.py`：项目任务快照、角色活动记录及本地修改收件。
- `preprocessing/import_manga.py`：本地拆页、索引与缩略图。
- `session.json`：项目级对话、当前书籍与页面、活动任务引用、待回答问题和工具记录。
- `tasks.json`：父制作任务、阶段任务、Creator／Reviewer 轮次及产物／审查引用。
- `pending_requests/`：绑定页面、目标和版本的待处理修改；可在认领前撤回。
- `sources/book-*/book.json`：真实文件页序与来源指纹。
- 既有 `runs/`：分格、脚本、审查、关键帧、视频等产物。

专业任务仍串行执行，每批最多 8 次工具决策。活动客户端会在已授权目标内续接，不再要求用户为内部批次边界反复发送“继续”；单次协调总决策有限，专业内容修订沿用原有限轮次。停止和重开不会自动续跑，明确恢复时核对原检查点和远端任务标识。本地停止不等于远端取消。

## 本机依赖与接口

```sh
uv pip install -e '.[preprocessing,local-ocr,book-import]'
```

MOBI 使用 `mobi==0.4.1` 的 KindleUnpack CLI，读取 OPF spine 和 HTML 引用顺序；该工具为 GPL-3.0-only，以独立命令行进程使用，未复制其源码。PDF 使用 pypdfium2 5.x；CBZ 使用 Python ZIP 和自然页序。文件损坏、加密或依赖缺失时明确报错，不自动切换解析后端。

沿用已配置 `gemini-3.8-flash`。幻灵提供显式选项：

```dotenv
HUANLING_TEXT_API=native
HUANLING_TEXT_TRANSPORT=curl
NO_PROXY=ai.huanling.icu
```

这些是本机针对 Python TLS 不兼容的明确配置，不自动探测或降级。curl 通过 stdin 接收请求与凭据，不把 Key 放进进程命令参数，也不关闭 TLS 验证。API 可显式选择 native 或 compatible，传输可选 requests 或 curl。本机使用 native + curl；兼容路径在复杂脚本上出现非 JSON／不完整输出，因此未作为本机默认。视频评审沿用现有原生协议及已明确选择的传输方式。后端能力检查保持现状，不自动切换模型；Lite／480P 验证依用户决定不属于这轮任务流程改造。

## 统一任务流程（2026-10-29）

右侧按发生顺序排列对话与任务卡片。卡片显示当前负责角色和状态，展开查看实际 Creator 提交、Reviewer 结论、依据和修订轮次；复用既有产物明确标注，旧项目缺少身份的日志只显示历史记录，不补造协作。MAGI、视频生成、下载和剪辑仍是工具，不包装成推理 Agent。

可以提出“完成这一页的镜头编排”或“制作到关键画面”。创作 Agent 通过 produce 委派必要阶段并在指定终点停止；超出已允许范围时显示明确操作。右上角阶段按钮只执行所选阶段，缺前置就提示；旧工作台的规划、修订、生成和恢复按钮也使用同一任务入口，预览与文件导入保持本地操作。

运行中发送要求会先区分用途。“现在做到哪了？”从本地任务记录回答，不创建修订；普通问题在安全检查点回答后继续。明确修改在当前调用和检查点保存后进入原修订／审查路径，缺少目标或版本冲突则等待决定。修改完成后可以检查新版本再继续原制作。

输入框运行时可选择“调整当前任务”或“稍后处理”。后续要求拥有独立身份，只有当前任务正常完成、目标与授权明确且客户端仍活动时才启动。失败、暂停、停止和重开不自动消费队列；未接收的要求可撤回。重开后若前一任务已正常完成，可在排队记录点击“开始处理”，仍按接收顺序推进。输入单独的“停止”与点击停止按钮使用同一本地中断入口，远端任务可能仍在运行。

选中画布对象，点击输入框内的加号可加入引用；旁边选择它是“目标”还是“参考”。目标决定改谁，参考只提供资料，引用固定真实运行与内容版本，切页不改变它。悬停标签可看版本；点击消息中的标签可查看对应原产物，失效会明确提示。当前只接入项目内对象、图片及已有视频的查看，不建设全局搜索；视频不能直接当作任意生成控制条件。

展开专业任务可以查看本次任务要求、允许修改范围、实际 Creator／Reviewer 调用、反馈接收者与专业回报。回报从真实产物和审查记录整理，不额外调用报告模型；流程自动交接与 Agent 决策分别展示，总 Agent 不能覆盖 Reviewer 的拒绝结论。

任务与画布双向定位：任务卡点击产物可展开并聚焦节点，节点详情可返回协作记录。恢复原视频查询／下载与继续制作分开；恢复下载不会重交任务，视频内容拒绝不会自动追加付费视频。
