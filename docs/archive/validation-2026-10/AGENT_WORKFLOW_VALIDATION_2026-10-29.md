# 统一任务与协作时间线验收

日期：2026-10-29。OpenSpec：`unify-agent-task-workflow`。

本轮整理任务推进与客户端交互，新增付费模型请求为 0。专业 Creator／Reviewer 的推理实现继续复用原流水线；模拟协作仅演示界面，不代表真实模型输出或成片质量。

## 已实施

- 自然语言制作与单阶段按钮共用父制作任务、阶段子任务和角色轮次记录，保存目标页面、版本、授权与产物引用。
- 现有客户端的规划、定向修订、视频生成及原任务恢复按钮也接入相同任务入口；本地预览和来源导入不增加协调模型调用。
- 已授权连续目标可推进至终点，单阶段入口保持只执行所选阶段。内部动作批次可由活动客户端续接，总决策和专业修订仍有限，停止／重开不自动执行。
- 在现有模型封装边界记录实际 Creator／Reviewer 开始、提交、审查、拒绝与复用；总 Agent 不覆盖专业审查，工具不伪装为推理 Agent。
- 运行中修改先保存到独立本地收件文件，在产物与检查点保存后处理，明确标出待处理、撤回、冲突或已应用；修订使用新运行并保留原版本。
- 右侧用统一时间线和折叠任务卡片替代对话末尾堆叠日志，支持任务／画布双向定位。
- 任务状态采用明确结果，专业角色事件不会打断画布进度。普通状态问答不能把旧任务标成完成，发送成功的草稿不再恢复为未发送输入。

## 原生客户端走查

使用最终构建的 macOS arm64 客户端。素材与任务保存在下列本地目录，不修改原付费样例：

- `results/simulations/f4b88ca5-d647-40ab-8bd5-388e45194c5d/`：本地模拟。
- `results/workflow-client-validation-20261029/`：复用已有真实通过的规划及已下载视频，检查任务与恢复入口。
- `results/workflow-preprocess-client-validation-20261029/`：真实本地分格与待处理修改检查。
- `results/workflow-simulation-failure-20261029/`：模拟执行失败后从第 13 个已保存步骤恢复，最终完成；API 调用为 0，此项为本地入口验证。
