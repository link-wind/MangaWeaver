# 本地创作演示与字号调整验收

日期：2026-11-05。OpenSpec：`align-canvas-with-approved-visual` 补充任务6、7。

## 功能

首页创作容器下方提供「体验演示」，创建独立模拟运行并自动启动。使用第94页漫画、6格分镜、4镜头规划、5张彩色关键画面、4段历史视频和已有整页有声预览，按本地步骤逐渐展示画布节点及对话内容。

Creator／Reviewer 活动来自明确标注的演示预设，包含编排退回再审，以及镜头03的视频退回反馈。在视频审查处暂停，可定位镜头或查看完整协作过程，再点击「继续演示」展示历史预览。该视频的原问题和未通过状态保留，不伪装重新生成或修订通过。正式项目不会写入演示内容，演示输入只读。
