# 编辑器视觉系统验收

对应变更：`refine-editor-visual-system`。

## 验收范围

- macOS Electron 42 客户端，常用窗口 1480×980，最小窗口 1080×720。
- 首页、成片卡片、画布产物视图、节点详情、创作对话、协作过程、停止与恢复、空态和缩放状态。
- 使用本地离线项目及本地模拟任务，没有提交付费模型请求，没有生成新的 AI 视频。
- 仓库在验收前已有多项未提交的 UI、Agent 和工程改动；本记录只对本变更涉及的视觉行为作判断，不把旧变更的未验收项一并勾选。

## 视觉规则

1. 首页只保留一个主标题。漫画附件、创作提示词、添加入口和开始按钮位于同一输入容器，最近成片以媒体封面打开，标题、日期和状态为次要信息。
2. 画布节点固定为四段层级：类型与状态、媒体、标题与元信息、按需操作。描述最多保留三行，空间不足时由详情承担全文。
3. 状态同时使用颜色、图标和文字。已完成为绿色，执行中为信息色，等待确认或修订为警告色，失败或中断为危险色；状态可供屏幕阅读器读取。
4. 标题、正文、控件和元信息只使用共享字号与字重层级。主色仅用于主操作、聚焦和当前选择，媒体保持原色。
5. 普通卡片无常态阴影；悬停和节点选择只增加一档浅深度和统一焦点环。对话框、菜单和浮层使用更高一档深度。
6. 左栏、画布和对话栏由分栏组件生成一条贴边分隔线，不再由相邻面板各画一条边框，也不为分隔线增加阴影。

## 实际客户端结果

| 区域 | 结果 |
| --- | --- |
| 首页常用窗口 | 单个创作容器、紧凑附件入口、主操作和媒体优先成片卡片层级正常；三张卡片没有横向溢出 |
| 首页最小窗口 | 长标题最多两行，输入容器保持完整，最近成片仍可滚动访问；Tab 顺序可到创作输入、添加漫画、继续项目、查看全部、列表菜单和项目卡片，回车可打开项目 |
| 画布常用窗口 | 节点顶部显示类型与状态，媒体、标题和简短元信息顺序稳定；选中节点出现统一焦点环，详细操作在详情内 |
| 画布最小窗口 | 顶部左侧工具与右侧制作控件分两行排列，未重叠；画布、对话栏和详情仍可独立滚动，三栏分隔线贴边且无阴影 |
| 缩放状态 | 节点与文字统一随视口缩放，远景保持真实节点结构，没有切换为胶囊；33% 总览仍能辨认标题和状态，15% 仅用于整体导航阅读 |
| 节点状态 | 已完成节点显示勾选与“已完成”，运行中显示加载图标与“执行中”；等待确认在对话中使用警告色，不再误用错误红 |
| 节点详情 | 标题、标签、正文、媒体和操作形成单一纵向阅读层级；长内容留在详情，不挤占画布主视图 |
| 创作对话 | 用户消息、创作过程、专业任务、产物和最终说明密度可区分；工具记录默认折叠，技术细节按需展开 |
| 流式追加 | 本地模拟运行期间，协作阶段和画布卡片逐步追加；公开说明从“执行中”更新至完成，没有一次性伪装成流式 |
| 停止与恢复 | 运行中点击“停止”后显示“已中断”并提示可继续；再次运行从已有进度继续，最终进入“已完成” |
| 历史阅读 | 展开协作过程后出现“回到最新消息”；点击后返回最新位置，历史节点和卡片仍可访问 |
| 等待与错误 | 离线样例的等待确认状态显示橙色文本和说明；失败、阻断和中断共享危险色，保留原因与后续操作 |

## 本轮修复

1. 状态徽标原先把所有“需要处理”的细分状态合并为错误红；现拆分信息、成功、警告和危险语义。
2. 画布节点原先用纯图标表达完成与运行，现补充可见短文字和完整的可访问名称。
3. 最近成片封面原先在外层按钮中再次渲染播放按钮，形成嵌套按钮；现由封面上的单个按钮承担打开项目，标题按钮保留，控制台不再出现嵌套按钮错误。
4. 清除了工作台后置样式中的旧阴影变量，统一使用主题中的普通、抬升和浮层三档深度。
5. 移除右栏自身边框，三栏边界只保留分栏组件的一条贴边分隔线。

## 未覆盖边界

- 本轮没有调用付费规划、生图或视频模型，不能据此证明外部渠道、生成质量和成本。
- 末轮 macOS 屏幕捕获接口间歇失败，因此最终微调通过最新开发客户端的可访问树、交互状态和控制台完成复核；页面整体视觉使用前一轮实际客户端画面确认。
- 15% 及更低缩放用于总览导航，不把这一层级的正文当作可阅读文本。
