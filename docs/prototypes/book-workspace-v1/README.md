# 整本漫画工作区 · 视觉初稿

日期：2026-11-05。对应方案：`../../BOOK_WORKSPACE_DESIGN.md`。

这是独立、可点击的 HTML 视觉稿，不是正式客户端的新功能。未修改 Electron、Python、模型配置或实际项目数据。

## 查看

在项目根目录运行：

```bash
python3 -m http.server 8766 --bind 127.0.0.1 --directory docs/prototypes
```

打开 `http://127.0.0.1:8766/book-workspace-v1/`。

- 全书总览：`index.html#overview`
- 第94页画布：`index.html#single-94`
- 94／95页对照：`index.html#compare-94`

页面也可直接打开本地 `index.html`，共享素材使用相对路径，需保留相邻的 `toonflow-canvas-v1/assets/`。

## 可以体验

- 单击页面选择，Shift 选择范围，多选后出现操作条。
- 双击打开页面，或使用「继续第094页」。
- 使用全部、制作中、需处理、已有成片筛选。
- 在原作90～99页间跳转、使用上一页和下一页。
- 打开双页对照，拖动分隔线，引用参考页，交换当前页，关闭对照。
- 对话／协作视图切换、分格展开、历史片段预览。
- 制作和发送按钮仅提示，不提交请求。

## 素材与数据

使用用户已提供的《入间同学入魔了》卷01本地漫画，共10张相邻原页。原图路径记录在 `assets.json`；编号沿用此前素材记录中的原作页码，原作94页对应提取文件 `image-090.jpg`，不得将这组展示编号直接当作导入器的文件页序。

彩色关键画面与视频复用此前已确认视觉稿的真实历史素材。图标、字体和对话结构沿用 `toonflow-canvas-v1`，没有生成新的漫画或动画。

所有全书页卡状态、批量任务进度和跨页对话均为演示数据，顶部常驻标注。第95页没有虚构动画产物，只展示真实原页和未制作的页面状态。正式版的浏览页、执行页、任务范围分离、草稿绑定、每页视口恢复、持久化和调度仍以设计方案及后续 OpenSpec 为准；此稿不验证这些后台行为。
