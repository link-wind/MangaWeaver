# MangaWeaver 视觉设计优化方案

日期：2026-11-02  
状态：设计方案，待实施。数值为首轮实现基准，需结合实际窗口校准。

## 1. 设计目标

将 MangaWeaver 做成轻巧、精致的桌面动画创作工具。白色外壳保持安静，漫画、彩色关键画面和视频形成视觉中心；文字、控件和运行状态保持清楚。

延续用户已确认的方向：减轻字重、缩小导航、缩小附件、取消首页顶部标题和右上角项目选择栏。画布保留目录／画布／对话三栏，可调宽度，分隔线贴合区域边缘且无阴影。输入框操作放在框内，不显示原生右下角缩放柄。

本轮优化设计文档，不代表客户端已经完成这些调整。现有停止、恢复、单阶段运行、真实流式输出、引用与权限功能继续作为交互设计前提。

## 2. 设计依据与筛选

使用本地 UI UX Pro Max 检索：

- `creative desktop workspace minimal`：采用 Minimalism & Swiss Style 的清晰网格、留白与字体层级。自动生成的 Hero／Features／CTA、金色强调和 Archivo／Space Grotesk 面向营销与作品集，不适用于当前中文桌面工具，不采纳。
- `productivity tool workspace`（product）：匹配 Productivity Tool，采用 Flat Design + Micro-interactions，以及功能性色彩与清楚层级。
- `keyboard focus component`（React）：采用弹窗焦点管理及关闭后返回触发入口。
- `progressive disclosure`（ux）：未取得适用的渐进披露条目；下文折叠方案沿用项目已有约定，不将其宣称为数据库建议。

参考分工：AFFiNE 的工作空间组织、Lobe UI 的 AI 输入与消息细节、shadcn/ui 的基础控件一致性。已有 React Flow 和 Lucide 足以支持当前画布与图标，不因美化整体更换组件库。

## 3. 视觉规范

### 色彩与材质

| 用途 | 基准 | 使用方式 |
|---|---|---|
| 内容与卡片 | `#FFFFFF` | 主要输入、媒体、对话 |
| 应用外壳 | `#F7F7F8` | 左侧导航 |
| 画布 | `#FAFAFB` | 低对比背景，网格仅在有助定位时显示 |
| 主文字 | `#24242B` | 正文、标题、主操作 |
| 辅助文字 | `#666671` | 页码、时间、参数；避免用透明度继续变浅 |
| 边框 | `#E9E9EF` | 分栏与容器；交互控件边界按实际对比度单独校准 |
| 强调 | `#6757E7` | 焦点、当前运行标记、少量选中细节 |
| 选中底色 | `#EEEBFF` | 小范围使用，不铺满整栏 |

黑色承载主按钮；彩色媒体提供主要视觉丰富度。绿色、橙色、红色仅表达真实状态，同时配文字或图标。常驻面板、分栏与普通卡片无阴影；浮层可用极轻阴影帮助辨认覆盖关系。不增加玻璃、渐变背景和大面积装饰色。

### 字体与比例

优先系统字体：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`，避免引入远程字体和中英文风格割裂。

| 对象 | 字号／字重 | 意图 |
|---|---|---|
| 首页主标题 | 30–32px／400 | 轻盈，保留辨识度 |
| 页面标题 | 20–22px／500 | 素材库、成片库、设置 |
| 分区标题 | 13–14px／500 | 明确层级，避免大标题堆叠 |
| 正文、输入 | 14px／400；行高 1.6 | 中文可读性优先 |
| 导航、按钮 | 13px／400–500 | 紧凑的桌面尺度 |
| 次要元数据 | 12px／400 | 只放日期、时长等辅助信息 |

轻量感主要来自减少粗体和清楚的间距，不靠低对比小字。正文不使用 300 字重；600 以上仅在确有必要的少数重点使用。

### 形状、间距与图标

- 使用 4／8／12／16／24／32／48px 间距序列；同一层级保持一致。
- 控件圆角 8px，媒体与内容卡片 12px，主输入容器 16px；避免层层嵌套圆角框。
- Lucide 图标默认 16px，统一笔画；小图标按钮命中区域至少 28–32px，主要操作约 36px 高。
- 桌面紧凑控件维持清楚的键盘焦点与 tooltip；触控场景再采用更大的命中区域。

## 4. 各页面设计

### 首页：安静的创作入口

移除首页顶部“创作空间”和右上角项目选择条。保留 macOS 窗口控制与可用拖动区域。

左导航默认约 176px，可调范围与现有实现协调；导航行高约 34px，选中用浅灰底。仅保留“开始创作／素材库／成片库”，设置固定底部。全局页面不展开项目内目录，进入画布后再展示书籍与页码。

主区以约 680–720px 宽的创作输入为视觉中心，标题与输入间距约 24px。窗口变窄时按可用宽度收缩。标题文案沿用“让漫画，成为动画。”，不再叠加功能说明段落。

附件是输入框内的小型素材条：约 36×48px 缩略图、文件名、页数（已知时）、移除按钮。整条高约 56px，不显示整页大图，不包一层独立的大导入卡片。文件名截断后可查看完整名称。

输入区域直接接收 prompt，默认总高度约 180–220px，随内容增长到上限后内部滚动。添加附件与素材库入口放在左下；参数按需展开；黑色发送按钮放右下。附件错误就近显示，已有草稿保留。

“继续当前项目”作为输入框下的轻量入口。首页成片最多展示三项真实记录，媒体优先，标题与时长放在卡片下或固定小区域；没有成片时不以虚构预览填充。生成参考图里的示意媒体不作为真实作品。

### 素材库：封面形成书架感

顶部一行“素材库”、搜索、导入，减少说明文字。封面采用一致的竖向展示区，完整显示漫画封面；卡片之间留 24–32px 间距。

默认只显示名称及格式／页数一行元数据。悬停或键盘聚焦可显示“添加到创作”，选取入口不依赖悬停才能使用。选材模式保留返回创作与原 prompt。空状态用一句说明和一个导入按钮。

### 画布：媒体优先，操作就近

三栏默认参考：左 192px、右 352px，中间占剩余空间；这是可调初始值，不覆盖用户已保存的栏宽。拖动分隔线增加透明命中区，线本身保持 1px 且贴合边缘。

首页去掉的全局标题条不迁移到画布。画布仍需简短的项目身份与打开／切换入口，放左栏顶部；制作范围、终点与运行／停止放画布顶部紧凑工具区，避免与右栏重复。

漫画原页 → 有序单格组 → 镜头规划 → 关键画面 → 视频，沿用真实产物与现有分组。节点标题约 13px，显示阶段／页码和状态；媒体为主体。组折叠显示封面、数量、真实状态，重新展开保留位置与顺序。

选中节点用细强调边线与低强度底色；悬停不抬升卡片、不改变尺寸。卡片顶部细进度条仅对有确定比例的阶段显示比例；未知进度用不定进度及阶段名，完成后收起。节点操作同时支持聚焦和菜单访问。

### 对话：对话连续，协作过程清楚

右栏顶部只保留简短“创作”标识与必要切换操作。普通对话按清晰文本流呈现，减少每段回复外套一层卡片。

每次委派作为一个任务单元：来源页／阶段、当前角色、状态、短结论。Creator → Reviewer → 修订过程以真实事件的角色标签与可展开时间线展示；同一内容不在摘要、消息和审查卡中重复全文。

真实公开文本持续追加到对应任务位置；展开依据、查看产物、恢复放在相关任务内。新事件不抢走用户正在阅读的位置。必须处理的问询与错误保持可见。

底部输入框保留目标、引用与已有权限选择，低频选项收进菜单。输入框留足文字空间，发送／停止就近；不得通过视觉简化隐藏当前目标或扩大模型调用授权。

## 5. 动效与交互细节

- 悬停和选中反馈约 120–160ms；展开／收起约 160–200ms，操作后立即提供反馈。
- 不为长任务制造假百分比，不给流式内容添加模拟打字效果。
- 图片预留尺寸，生成产物逐步出现时尽量保持当前视口；不自动把画布缩放到全部节点。
- 焦点可见；菜单 Escape 关闭并返回触发控件；弹窗正确管理焦点。
- 支持减少动态效果，停用非必要位移与动画。

## 6. 实施顺序与验收

1. 统一字体、颜色、间距、圆角及图标尺度，替换散落的不一致样式。
2. 完成首页导航、去顶部标题、紧凑附件与主输入布局。
3. 统一素材库和成片库的媒体比例、卡片与空状态。
4. 调整画布工具区、节点、进度和对话展示，保留已有运行能力。

优先改现有组件与样式，不增加新的主题框架。只在设计确认后进入实施；视觉参考图不是完成证据。

验收以实际客户端为准：1440×900 与 1280×800，并检查窄窗口和界面放大；首页附件不抢占输入区，三栏不遮挡，长文件名和长中文回复正常；文字对比度、键盘焦点、流式追加、折叠、停止／恢复与来源归属可用。使用现有本地素材和模拟任务验证，不调用付费模型，不为纯视觉改动机械增加测试。
