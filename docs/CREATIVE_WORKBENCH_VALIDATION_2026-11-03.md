# Toonflow 借鉴优化：实施与验收记录

对应 OpenSpec：`refine-creative-workbench`。保留 Electron／React／Python JSONL、三阶段和 Creator／Reviewer，本轮没有更改模型渠道、提示词、重试或 H3 能力，也没有调用付费模型。参考依据见 `TOONFLOW_ENGINEERING_REFERENCE.md`、`TOONFLOW_INSPIRED_DESIGN.md`。

## 已接入的交互

- 首页通过就地选材弹层复用完整书架，支持整本／单页筛选、主动导入和原有去重；取消不更改输入。当前项目名称显示在首页保存位置入口。
- 节点保留媒体和短状态；选中后的详情区承接长文本、修改、协作和候选查看。未选中节点收起单阶段执行按钮，组级入口保留。
- 草稿保存明确独立于制作，保留目标节点、引用和送达方式。保存按钮位于输入框内部；保存本身不调用模型。
- 搜索只使用已加载节点的名称、页码和阶段。点击沿用原有节点身份检查、分组展开、布局等待和定位确认，不加载整本漫画。
- 关键画面详情可浏览已有候选、当前采用标记、审查依据与来源版本。预览只读。受限采用重新检查计划和候选读取签名、图像哈希、制作输入、来源、Reviewer 与原 ProductionPlan 校验；已有视频任务时拒绝替换。动作镜头的新候选还需整段序列审查，不能直接替换。
- 确定性工具记录默认折叠，失败摘要常驻；公开文字和真实阶段协作分开阅读。协作详情保留轮次、Creator／Reviewer、审查意见、产物和定位入口。
- 队列显示“引导当前任务／本轮结束后处理”及真实状态，复用已有撤回、处理和停止入口。运行中消息走独立收件箱，不被画布写锁阻塞。
- 历史引用显示实际页码和名称，保留原运行身份。展开过程时停止自动跟随，提供回到最新消息入口。
- 设置包含本机环境和只读版本；进入、退出及 Escape 的焦点处理保留原画布。沿用白色界面和无阴影分栏。

## 保存与媒体边界

JSON 在同目录使用唯一临时文件并原子替换，不改变原产物事件。桌面读取快照提供内容签名，保存携带 `expected_revision`；`null` 表示读取时不存在，与不提供校验的内部制作调用区分。来源修订／画布保存在已有锁内比较，冲突返回 `EDIT_CONFLICT`，不强制覆盖。

画布按运行串行保存；回包只推进对应运行基准。新编辑仍保留 dirty 状态。项目、运行、页面、阶段切换及窗口关闭等待当前编辑和视图写入；重新读取需明确确认放弃未保存内容。窗口中的活动任务仍先走既有停止确认。

媒体使用独立租约，共享资源计数归零才回收 token；卸载前返回的迟到请求立即释放。renderer 重载／销毁释放其剩余租约，项目切换不清空其他使用者授权。Range 播放和本地文件保持不变，关键画面签名更新会重新获取媒体。

每个流式事件批次只克隆一次历史，保留原分支、序号及重复事件过滤；结束事件仍立即补齐待显示文字。没有增加 SSE 服务、虚拟列表或新的 Agent 服务。

独立目录：`results/refine-creative-workbench-validation/`，不作为公开素材提交。

4. 仅在测试目录制造外部文件修改；保存显示冲突，保留本地输入和外部磁盘版本，离开画布被阻止；重新读取先显示放弃修改确认，再读回外部草稿。
5. 选材弹层和原生导入入口能够打开。原生文件选择器对已选图片仍返回禁用的“打开”，未将该次导入／确认选材记为通过。
