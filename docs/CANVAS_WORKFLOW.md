# 漫画页与创作画布

本次目标：在首页同时提供漫画页与创作提示词，进入一个支持平移、缩放、节点查看与阶段修订的画布，而不是在多个表单页面间切换。

## 输入与保存

首页“添加漫画页”只选择本地文件，不上传、不调用模型；输入创作提示词后点击“进入创作画布”，选择项目保存位置并创建运行。原始页面复制到运行内 `input/page.*`，初始提示词和画布状态保存在 `canvas.json`。

初始提示词在分格导入时绑定到来源的 `creative_brief`，实际进入来源脚本、镜头编排、动作演出、关键画面及对应审查的上下文。空 brief 不参与旧来源序列化，保持既有签名兼容。模型、分辨率和硬性时长限制仍来自明确的运行配置。

## 画布

画布显示：整页漫画 → 按阅读顺序纵向排列的漫画单格 → 镜头规划 → 各镜头 → 各时间锚点画面 → 已有视频。来源脚本继续由原 Agent 生成，按格内容与审查收在单格详情及镜头规划详情中，不再占独立画布列。

- 使用 React Flow 提供平移、缩放、小地图、节点选择和位置拖动。
- 连线表示来源和生成关系，不是另建可执行 DAG 或通用 Agent 编排器。
- 节点来源于真实产物。未生成内容显示等待，审查拒绝不标记通过。
- 选中节点后可查看文本、图片、视频及已有审查详情；选中目标同时进入右侧修改上下文。
- 布局坐标、修改草稿和提交记录保存在运行内 `canvas.json`，重开运行恢复。
- 原素材校正复用现有编辑器，“返回画布”继续流程；源内容改变时创建新运行。

## 阶段检查点与中途修改

手动阶段运行只执行所选阶段并暂停；对话明确指定连续制作终点时，在已有授权内通过审查后继续到终点。检查点沿用 `planning_draft.json`，`planning_pause.json` 仅标记暂停位置；继续仍执行原 Creator／Reviewer 循环。

选中镜头或关键帧后，在右侧写修改要求并明确提交。请求带阶段和目标 ID，实际进入规划的反馈路由，保留未受影响且审查通过的产物。运行中可以发送待处理修改，绑定当前页、目标和版本，并在被认领前撤回；结果与检查点保存后再处理，不并发修改正在执行的输入。

已有付费视频任务时，应用修改创建新的修订运行，仅引用原来源与规划检查点，不复制视频任务 ID，不重新提交旧任务。源图片和旧版本保留。实验运行仍只读，不包装为正式生成入口。

## 计费与验证边界

进入画布、拖动、查看、保存草稿不调用模型。“开始／继续阶段”“应用修改”和视频生成是明确的模型操作。视频后端继续采用配置的 H3 Lite / 480P；渠道不支持时明确阻止，不能自动更换模型。

检查覆盖初始 prompt 绑定、旧来源序列化兼容、阶段暂停阻止下游生图、检查点继续、修订不复制付费任务、画布的节点／来源关系及布局恢复。不新增付费生成作为界面验收。

## 书籍、多页与折叠

首页发送并选择项目位置后立即进入画布，先显示本地导入进度。本地导入保存后先呈现书籍节点，无需等待 Agent 回复。书籍保留完整文件页序索引，首批只转换前 10 页；书籍节点每组浏览 10 页，下一组或跳页时才加载该组图片，直接展开指定页只补载需要的页面。CBZ 按成员读取、PDF 按页渲染；MOBI 首次仍需解包，但只转换首批图片，解包结果保存在项目中供后续使用。旧全量导入书籍仍可打开。

点击选择缩略图，或输入 `2-4,8` 这样的文件页序范围，再点“展开”；双击单页也可直接展开。跳转只浏览本地页面，不制作。单页展开会切到该页，范围展开保留范围内的当前页或切到第一项。

已展开页面按文件页序形成独立分支。页面标题中的箭头收起整页，阶段标题中的箭头把漫画分镜、镜头、关键画面或视频列收成汇总卡。汇总卡显示数量、缩略图和真实状态，新增产物只更新汇总，不自动展开。连线连接汇总卡，展开恢复节点。拖动只改变显示位置，不改变阶段或来源归属。

点击页面卡片或该页内容切换当前页，右侧创作栏会显示页码。对话和节点修改默认针对当前页；运行中保持当前制作目标，制作范围也暂不可改。不同页的输入草稿互相隔离。折叠隐藏的节点仍有业务身份，Agent 定位时先展开所属页和阶段，实际渲染、定位完成后才回传回执。

右上角的“运行阶段”明确选择漫画分格、来源脚本、镜头编排、演出方案、关键画面或视频成片，默认指向下一待办阶段。点击运行只执行所选阶段并暂停；阶段内仍由原 Creator／Reviewer 创作与审查。已完成阶段复用结果；需要修订时通过对话提交要求。上游条件不足时清楚提示，不跳过审查。整页、阶段列和镜头规划卡片的小播放按钮提供同等阶段入口。

页面卡标题的复选框用于选择运行目标，和书籍节点的“展开页面”分开。勾选后右上角显示“运行所选 N 页”，按所选阶段顺序处理；未勾选则只运行当前页。出现错误、待回答时后续页不开始；停止后也不自动继续剩余队列。对话输入框的“对话制作权限”只控制普通对话，默认仅本地处理；显式点击阶段运行独立授权该阶段，不会被这个默认值限制在分格。生图与视频的阶段按钮会调用对应模型，浏览与折叠不计费。
