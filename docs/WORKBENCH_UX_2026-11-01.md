# 工作台界面优化验收（2026-11-01）

OpenSpec：`refine-workbench-experience`。沿用已有 Electron／React／Python 和 Manga2Animate 固定参考版本；本轮不改模型、生成流程、付费权限或产物协议。

## 界面与交互

- 白色三栏，统一标题、控件、留白和焦点样式，分隔线不带阴影；保留用户已保存的栏宽。
- 项目目录显示漫画页、独立运行和成果；十页一组，可跳页，浏览目录不提前加载全书。
- 首页保留漫画与 prompt 为主入口；模拟、导入、扫描收进次级菜单；成片名称直接打开项目。
- 画布单击选择、双击详情。右栏创作／详情切换保留输入草稿、引用和对话；小地图默认关闭，首次定位后不因运行刷新强制适配。
- 顶部明确当前范围和制作终点，通过既有 `until` 操作执行；节点按钮沿用单阶段执行。停止与恢复机制不改。
- 输入框自动增长，目标／参考直接传递用途，保留制作范围和运行中消息送达选择。
- 工具、专业事件、任务事实合并为任务摘要，Creator／Reviewer 过程收起；问题与恢复按钮可直接处理，原始参数、任务及事件仍可查看。
- 对应任务错误不再重复为全局横幅；文件／环境等独立错误仍显示。内容审查中的“动作超时”不当作网络故障。
- 修复整本书与历史独立成片共存时的画布遗漏和陈旧页码标签。

## 验收证据

原生应用接口实测，使用隔离配置与 `results/ui-experience-validation-20261101/project/`：

1. 首页、项目打开；12 页本地 CBZ 测试夹具首轮仅载入 10 页，左栏切至 11—12 页并按需打开第 12 页。
2. 单击选中整页节点仍在创作栏；双击进入详情，返回后原草稿保留；加号加入参考显示正确用途。
3. 首页目录栏及画布对话栏实际拖动成功；小地图从隐藏切换为显示；协作与技术详情默认收起，历史恢复入口可见。
4. 首页创建本地模拟，运行后停止，显示中断和保留进度；再次运行至完成，协作过程包含编排审查退回及后续修订。结果是 FFmpeg 本地静帧预览，不是模型成片。
5. 打包应用打开原有成片及其项目，保留历史会话和恢复入口；本轮不重跑付费生成。

检查通过：桌面 19 项、Python unittest 43 项、TypeScript／Vite 构建、OpenSpec 严格校验、macOS ARM64 打包。构建仍有既有的前端包体积提示；应用沿用未签名本地构建。

最终验收包：`desktop/release-ui-review/mac-arm64/MangaWeaver.app`。最后的独立成片定位修正在隔离 Electron 中再次确认：显示独立运行、完整分镜／关键画面／视频／动画预览，无陈旧书籍页码。为保留当前已打开客户端的窗口，最终包单独输出，关闭现有应用后打开此包即可体验完整改动。日常 `npm run pack` 仍输出原 `desktop/release/`。

本轮新增付费模型调用为 0。CBZ 是复用单张图片的界面测试夹具，不作为真实漫画质量或 MAGI 推理验收证据。
